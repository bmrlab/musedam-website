从创建草稿到发布商品，再到预览、分享和下载，按当前操作查阅即可。所有路径均相对于 `https://open.musedam.cc/api/product`；完整参数见[接口文档](./product-library-reference)。

## 创建商品

调用 `POST /products` 创建草稿，需要 `products:create`。成功返回 `201`，`data` 包含商品详情，响应头包含强 `ETag`。

1. 准备商品名称、SKU，以及需要关联的品牌、分类和素材 ID。
2. 如需指定模板，传入 `templateId`；否则按下方的模板匹配顺序选择。
3. 创建后补齐字段，再调用[发布接口](#publish-product)。创建请求不能设置 `status` 或 `templateVersionId`。

<details>
<summary>创建和更新可以填写哪些字段？</summary>

| 字段 | 值 | 创建默认值 / 更新方式 |
| --- | --- | --- |
| `name` | 字符串，最多 255 个字符 | 空名称 / 省略时保留 |
| `spu` | 字符串，最多 64 个字符，或 null | null；纯空白裁剪为 null / 省略时保留 |
| `description` | 字符串或 null | null / null 清空 |
| `brandId`、`categoryId` | 正整数或 null | null / 省略时保留；最终分类必须属于最终品牌 |
| `ownerUserId` | 同一团队成员 ID 或 null | 无负责人 / 省略时保留，null 清空 |
| `templateId` | 同一商品库中有效的模板 ID 或 null | 指定模板或自动匹配 / 更新时不能提供 |
| `templateFields` | 以自定义字段 ID 为键的对象 | 空 / 浅合并，null 清空单个字段 |
| `coverAssetId` | 素材库素材 ID 或 null | 无显式封面 / null 清空 |
| `imageAssetIds` | 素材库素材 ID 数组 | 空 / 省略时保留，空数组清空；未提供 `coverAssetId` 时，第一张图片成为封面 |
| `relatedAssetIds` | 素材库素材 ID 数组 | 空 / 省略时保留（包括旧版关联），空数组清空 |

请求体只接受这些字段。API 创建者和更新者的归属独立于商品负责人，API key 的创建者不会自动成为负责人。

</details>

<details>
<summary>重试创建时，商品和媒体会返回什么？</summary>

- 创建可携带 `Idempotency-Key`，在 24 小时内按团队、API key 和操作识别同一请求，详见[创建与幂等重试](./product-library-write-conventions)。
- 重放保留首次结果的非媒体字段、业务文本、链接值和原始 ETag；记录只保存原始媒体 ID，不保存存储 URL 或签名。
- 返回媒体前会重新检查当前权限、商品可见性、文件有效性，以及原 ID 是否仍位于相同关联槽位。新增关联不会加入首次结果；结构化自定义值中已解除关联的媒体也会被移除。
- 下载属性仍需要商品读取和下载权限。已删除或不可见的商品不会因重放重新出现，文本和 URL 字段仍作为普通业务数据返回。

</details>

## 使用模板和自定义字段

新商品保存所用模板的最新版本。读取商品返回的 `templateDefinition` 来解释 `templateFields`，不要使用模板当前的最新定义；模板后续修改或删除不会改变已有商品的版本和值。

商品创建后，普通 PATCH 不能更换模板。模板的创建、配置和绑定方式见[模板管理](./product-library-template-writes)。

<details id="product-template-definition">
<summary>商品返回的模板定义有哪些字段？</summary>

`templateDefinition` 是商品保存的模板版本，无模板时为 null。读取它不需要 `templates:read`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `groups` | 对象数组 | 分组及其字段定义，见[模板定义字段](./product-library-template-writes#template-definition) |

`templateFields` 以定义中的字段 ID 为键，不使用字段名称或 key。普通值保留 JSON 类型；图片和文件值返回[媒体对象](#product-media-fields)数组。

</details>

<details>
<summary>未指定 templateId 时，如何选择模板？</summary>

- 显式提供有效的 `templateId` 时，直接使用它。
- `templateId` 省略或为 null，且提供非 null 的 `categoryId` 时，依次查找：分类或祖先分类绑定、该分类所属品牌绑定、商品库默认模板。
- `categoryId` 省略或为 null 时，即使提供 `brandId`，也只考虑商品库默认模板。
- 未找到模板时，商品没有模板。已有商品的固定版本缺失或不匹配时，返回内部错误，不会改用其他版本。

</details>

<details>
<summary>自定义字段值的格式与素材限制</summary>

| 字段类型 | 输入格式 |
| --- | --- |
| `number`、`currency` | JSON 数字 |
| `dateRange` | 起止日期字符串组成的有序数组 |
| `checkbox` | 选项值数组 |
| `image`、`file` | FilePath ID 数组，或 null |
| `richtext` | HTML 模式为字符串；delta 模式为 `{ "ops": [...] }` |

- `templateFields` 按固定版本中的字段 ID 校验。更新时浅合并，值为 null 时清空对应字段。
- 草稿允许缺少必填字段，但已提交及合并后的值仍须满足类型、枚举和素材限制。日期必须是真实日历日期，包括有效闰日；日期范围须有序，现有 datetime 和时区格式仍受支持。
- 图片/文件字段遵守该版本的数量、大小和可接受类型配置；图片槽位只能引用图片素材。
- 单次请求的封面、图片、关联素材和自定义字段合计最多引用 100 个素材。此处只关联已有素材，不上传、下载或同步素材。

</details>

## 更新商品

调用 `PATCH /products/{id}`，需要 `products:update`。只传需要修改的字段；成功返回 `200`、商品详情和强 `ETag`。

| 当前状态 | 更新要求 |
| --- | --- |
| 草稿 | 可缺少必填值，已填写的值仍须合法 |
| 已发布 | 额外需要 `products:publish`；校验完整商品，成功后保持发布状态 |

需要避免覆盖他人的修改时，先读取商品，再将响应的 `ETag` 原样放入 `If-Match`。值已过期时返回 `412 precondition_failed`，商品保持不变；详见[并发更新与重试](./product-library-write-conventions)。

<details>
<summary>只改一个字段，为什么仍可能校验失败？</summary>

- PATCH 和发布会按商品保存的模板版本校验整个结果，包括未修改的已存储值。
- 旧数据中的无效 URL、邮箱或素材也可能导致 `422 validation_failed`。查看 `details[].field`，在同一次 PATCH 中或通过浏览器修正后重试。
- 校验或事务在提交前失败时，字段和素材关联一起回滚，不会部分修改或丢弃其他字段。
- 已提交的修改仍可能无法返回响应，按[写入结果与恢复](./product-library-write-conventions#write-outcomes-and-audit-durability)核对，不能仅凭响应失败判断回滚。

</details>

## 发布或恢复草稿

调用 `PATCH /products/{id}/status`，请求体只能是 `{"status":"published"}` 或 `{"status":"draft"}`。无论目标状态是否变化，都需要 `products:update` 和 `products:publish`。

| 操作 | 校验与结果 |
| --- | --- |
| 发布 | 校验固定版本的必填字段、类型、选项及素材可用性和配置限制；缺少字段返回 `422` 和字段详情 |
| 首次发布 | 设置 `publishedAt`；重复发布保留此时间 |
| 恢复草稿 | 清空 `publishedAt`，之后允许不完整的草稿编辑 |

默认必填项为名称、SKU 和封面，具体以商品保存的模板版本为准。成功返回商品详情和新的强 `ETag`；可选的 `If-Match` 过期时返回 `412`，不改变商品。

## 删除商品与处理错误

调用 `DELETE /products/{id}`，需要 `products:delete`；删除已发布商品还需要 `products:publish`。这是软删除，成功返回 `200`、`data: {"id": 123}` 和新的强 `ETag`；重复删除返回 `404`。

删除也支持可选的 `If-Match`，校验方式与更新相同。

| 错误 | 处理方式 |
| --- | --- |
| `422 validation_failed` | 查看可选的 `details[].field` 和 `message`；修正字段或外部、已删除、无效的引用 |
| `409 sku_in_use` | 更换 SKU；已软删除商品的 SKU 仍参与唯一性校验 |
| `404 not_found` | 检查商品 ID 和所属商品库；外部、已删除或不存在的商品均返回此状态 |

## 预览与下载链接

展示商品媒体时使用 `previewUrl`。需要原文件时，检查 `downloadUrl`，或使用下一节的下载接口；能预览不等于有下载权限。

| 链接 | 返回条件 | 服务签发链接的有效期上限 |
| --- | --- | --- |
| 派生预览 | 具备相应查看权限 | 3600 秒 |
| 图片原图预览回退 | 仅适用于图片，`view_only` 也可能返回 | 300 秒 |
| `downloadUrl` | 关联可解析且可见，`usable` 或更高角色，同时具备 `products:read` 和 `products:download` | 300 秒 |

所有服务签发链接还受 API key 的到期时间限制。链接过期后重新获取商品数据，不要将签名 URL 当作素材 ID 保存。

<details id="product-media-fields">
<summary>封面、图片和关联素材返回哪些字段？</summary>

`cover` 是一个媒体对象，无封面时为 null；`images`、`relatedAssets` 和自定义图片/文件值为媒体对象数组。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | 整数或 null | 素材查询返回的 ID（FilePath ID），不是 AssetObject ID 或商品素材关联 ID |
| `name`、`mimeType` | 字符串或 null | 文件名、MIME 类型 |
| `size` | 字符串或 null | 十进制字节数，如 `"2048"`，不是 JSON 数字 |
| `width`、`height`、`duration` | 数字或 null | 媒体尺寸和时长 |
| `previewUrl` | URL 或 null | 用于展示的预览地址；不可用时为 null |
| `downloadUrl` | URL 或 null，可省略 | 原文件地址；返回条件见上表 |
| `downloadUrlExpiresAt` | 时间字符串或 null，可省略 | 下载地址的到期时间，RFC 3339 格式 |

</details>

<details>
<summary>链接缺失、旧版媒体和外部预览如何处理？</summary>

- 非图片素材只返回派生预览，原始 PDF、压缩包和文档不会作为预览回退。素材库素材查询和模板配置只包含预览。
- 缺少下载权限或关联无法解析时，会省略 `downloadUrl` 和 `downloadUrlExpiresAt`；已授权但原文件不可用时，这些值可能为 null。
- 已存储的外部 DAM 缩略图或预览，只对未设置过期时间的 API key 返回，并先排除已知原文件 URL。它们的有效期由第三方控制，不保证短有效期，也不保证校验提供方签名。
- API key 设置了 `expiresAt` 时，过期时间无法验证的外部预览返回 null。查询参数中形似签名的值不能作为可信的过期依据。
- 服务签发的链接仍遵守上表限制；签名失败时不会返回原始存储 URL。

</details>

## 分享、下载与历史

按使用目的选择接口。下面的角色和权限均在每次请求时检查。

| 目的 | 所需角色与权限 |
| --- | --- |
| 创建分享 | `usable` 或更高角色，`products:read` 和 `products:share`；允许下载时还需 `products:download` |
| 下载或导出 | `usable` 或更高角色，`products:read` 和 `products:download`；`usable` 只可访问已发布商品 |
| 撤销团队分享 | `manage` 和 `products:share`，不额外要求 `products:read` |
| 查询团队历史 | `manage` 和 `products:history`，不额外要求 `products:read` |

### 创建与撤销分享

使用 `POST /product-shares` 分享固定的 1–100 个已发布商品。返回绝对访问 URL，访问者无需登录或 API key。

| 参数 | 可选值 |
| --- | --- |
| `expiresInDays` | 7、30、90 或 null（不过期） |
| `allowDownload` | 是否允许访问者下载 |
| `accessCode` | 可选，四位数字 |

分享展示商品的当前内容；未发布或已删除的商品会隐藏。分享属于团队，创建 API key 的到期、停用、撤销或权限变化不会使其失效；需要停止访问时调用 `DELETE /product-shares/{id}`。

### 下载原文件

1. 调用 `GET /products/{id}/download-assets`，获取候选项的 `assetKey` 和 `downloadable`。此步骤不返回媒体 URL，也不创建下载记录。
2. 调用 `POST /product-downloads`，设置 `kind: "assets"` 和 `productIds`。可用 `assetKeys` 选择文件，省略时选择全部原文件。
3. 单个文件返回原附件，多个文件返回 ZIP。缺失的原文件不可下载。

只取单个文件也可调用 `GET /products/{id}/download-assets/{assetKey}`，将候选 key 编码为路径片段；它不是素材 ID。每次提取都会重新检查权限。

### 导出商品表格

调用 `POST /product-downloads`，设置 `kind: "export"`。`format` 可选 `xlsx`（默认）、`csv` 或 `json`，不能提供 `assetKeys`。

- `locale` 默认为 `zh-CN`，只影响系统标签和状态，不改动自定义标签或值。
- `includeAssetUrls` 默认为 true。表格中的链接指向需要 Bearer 请求头的单文件接口，URL 不包含密钥；直接点击无法携带该请求头。
- 需要让浏览器访客免凭证访问时，创建商品分享。机器同步使用商品读取接口中的稳定字段，不使用本地化表格。

### 查询记录与重试下载

下载和导出通过 `X-Download-Record-Id` 返回记录 ID；重用已有记录时，响应头包含 `X-Idempotency-Replayed: true`。`requested` 仅表示请求已接受，不表示传输或本地保存完成；接受后检测到准备或传输失败时标记为 `failed`，重试不会重置状态。

查询 `GET /product-shares` 或 `GET /product-downloads` 可查看团队历史。省略 `productId` 查询全团队，提供一个商品 ID 则查询相关操作；支持 `page` 和 `pageSize`，按新到旧返回。

<details id="product-snapshot-fields">
<summary>记录中的商品快照有哪些字段？</summary>

分享和下载记录的 `products` 数组保留操作发生时的商品信息，不随商品后续修改更新。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | 正整数 | 商品 ID |
| `name` | 字符串 | 当时的商品名称 |
| `spu` | 字符串或 null | 当时的 SKU |

</details>

<details id="file-snapshot-fields">
<summary>下载记录中的文件快照有哪些字段？</summary>

下载记录的 `files` 数组保留首次接受操作时的文件信息。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | 字符串 | 文件快照标识 |
| `productId` | 正整数 | 所属商品 ID |
| `name` | 字符串 | 当时的文件名 |

</details>

<details>
<summary>同一次下载重试时，如何避免重复记录？</summary>

- 在 24 小时内复用同一 `Idempotency-Key`，作用域为团队、API key 和操作；POST 下载与单文件 GET 的作用域不同。
- 匹配的重试复用首次记录及快照，但会重新鉴权、读取当前内容并传输，不缓存文件字节。
- 同一 key 改变输入返回 `409`。省略 key、换用新 key 或超过保留期，均视为新操作，不是永久去重。
- 附件交付开始前，错误保留具体错误码；记录已提交或重放时还包含 `mutationOutcome`。重试该已接受操作时，保留原始幂等 key。
- 普通商品读取、预览及直接访问存储 `downloadUrl` 不进入业务下载历史。

</details>

<details>
<summary>团队历史包含哪些记录？</summary>

- 包含浏览器操作和团队其他 API key 的记录，不按当前 key 或创建者自动过滤。
- 按商品筛选仍返回完整操作，包括同一次操作中的其他商品和文件。
- API key 的 ID 和名称快照保留用于归因，不因 key 后续变化而消失。
- 历史接口只接受 `productId`、`page` 和 `pageSize`；未知或重复参数会被拒绝。

</details>
