`POST /api/product/products` 需要 `products:create`，返回 `201`。
`PATCH /api/product/products/{id}` 需要 `products:update`，返回 `200`。两者都会在标准信封中返回商品详情 DTO，并返回强 `ETag`。
PATCH 接受可选的 `If-Match`；过期的校验值返回 `412 precondition_failed`。
POST 接受可选的 `Idempotency-Key`，采用共享的 24 小时、团队/key/操作范围。

请求体仅接受以下属性：

| 属性                    | 值                                | 创建时默认值 / PATCH 行为                                                          |
| ----------------------- | --------------------------------- | ---------------------------------------------------------------------------------- |
| `name`                  | 字符串，最多 255 个字符           | 草稿名称为空 / 省略时保留                                                          |
| `spu`                   | 最多 64 个字符的字符串，或 null   | Null；仅含空白时裁剪为 null / 省略时保留                                           |
| `description`           | 字符串或 null                     | Null / 显式 null 时清空                                                            |
| `brandId`, `categoryId` | 正整数或 null                     | Null / 省略时保留；结果中的分类必须属于结果中的品牌                                |
| `ownerUserId`           | 同一团队成员 ID 或 null           | 无负责人 / 省略时保留；显式 null 时清空                                            |
| `templateId`            | 同一商品库中有效的模板 ID 或 null | 选择此模板；null/省略时使用下方的解析规则。PATCH 中会被拒绝                        |
| `templateFields`        | 以自定义字段 ID 为键的对象        | 空 / 浅合并；null 值清空对应的单个字段                                             |
| `coverAssetId`          | 素材库素材 ID 或 null             | 无显式封面 / null 时清空封面                                                       |
| `imageAssetIds`         | 素材库素材 ID 数组                | 空 / 省略时保留图片；空数组时清空；除非提供了 coverAssetId，否则第一张图片成为封面 |
| `relatedAssetIds`       | 素材库素材 ID 数组                | 空 / 省略时保留关联（包括旧版链接）；空数组时清空                                  |

创建时，显式指定的有效 `templateId` 优先。当其省略或为 null 时，提供非 null 的 `categoryId` 会启用分类/祖先分类绑定，其次是该分类所属品牌的绑定，最后是商品库默认模板。当 `categoryId` 省略或为 null 时，即使提供了 `brandId`，也只会考虑商品库默认模板。如果未解析到任何模板，商品将没有模板。

创建始终生成草稿。Status 和 templateVersionId 不是请求体属性。对已发布商品执行 PATCH 还额外需要 `products:publish`，会保持其发布状态，并校验完整的结果商品。提交前的校验或事务失败会将标量变更和媒体关联一并回滚。已提交的变更仍可能无法返回响应，请按[写入恢复规则](./product-library-write-conventions#write-outcomes-and-audit-durability)处理。

草稿中可以缺少必填字段。提交的值以及合并后的值仍必须具有有效的类型和枚举选项。日期和日期范围值必须是真实存在的日历日期（包括有效的闰日）；日期范围必须有序。现有的 datetime 和时区格式仍受支持。图片/文件类自定义字段接受素材库素材 ID 数组或 null，并遵守固定版本中该字段的数量、大小和可接受类型配置。一个请求最多可包含 100 个素材引用（总计），包括封面、图片、关联素材和自定义字段。它不能上传、下载或同步素材。图片槽位要求使用图片素材。

自定义值使用现有商品固定的不可变定义，即使在模板被编辑或软删除之后也是如此。固定版本缺失或不匹配时，会以通用内部错误失败。新商品会固定所选或解析出的模板的最新版本。PATCH 无法迁移模板。

`PATCH /api/product/products/{id}/status` 仅接受
`{"status":"draft"}` 或 `{"status":"published"}`，并且始终同时需要
`products:update` 和 `products:publish`，即使请求的状态与当前状态相同。它返回商品详情 DTO 和新的强 ETag。
`If-Match` 是可选的；过期的校验值返回 `412`，且不会修改该行。发布会校验完整的固定版本定义，包括必填的系统字段和自定义字段、自定义类型/选项，以及已存储图片/文件的可用性和配置限制。缺少字段时返回 `422` 并附带字段详情。默认情况下，名称、SKU 和封面为必填；固定版本的模板可以覆盖系统字段的必填要求。首次发布会设置 `publishedAt`；重复发布会保留该值。恢复为草稿会清空 `publishedAt`，并允许之后进行不完整的草稿编辑。

`DELETE /api/product/products/{id}` 需要 `products:delete`；已发布商品还额外需要 `products:publish`。它会软删除该行，并返回 `200`、`data: {"id": 123}` 以及新的强 ETag。可选的 `If-Match` 使用相同的校验规则。重复删除返回 `404`。

校验失败返回 `422 validation_failed`，并可附带包含 `field` 和 `message` 的 `details` 条目。外部/已删除/无效的引用属于校验错误。重复的 SKU（包括已软删除的商品）返回 `409 sku_in_use`。外部、已删除或不存在的商品 ID 返回 `404`。API 的创建者/更新者归属独立于人工负责人；key 的创建者绝不会自动成为商品负责人（Product Owner）。

幂等重放会保留原始的非媒体字段和原始 ETag。它存储的是原始媒体 ID，绝不存储存储 URL 或签名。重放的媒体仅限于那些仍存在于相同当前关联槽位中的原始 ID；较新的关联不会进入原始结果。当前 key 的权限、商品可见性和文件有效性会被重新检查。下载属性仍同时需要商品读取和商品下载权限。已删除/不可见的商品不能通过已存储的结果恢复。

结构化自定义值中的嵌套媒体遵循相同的投影规则。快照会记录已授权的文件/对象 ID，不包含素材快照和存储凭据；响应会重新投影这些引用。重放会保留原始的业务文本和链接值，同时移除不再与该自定义字段关联的嵌套媒体。标量文本和 URL 字段仍属于普通业务数据。

PATCH 和发布会依据固定版本定义校验整个结果商品。因此，浏览器端遗留的值（例如无效的 URL 或邮箱）可能导致一次无关的 API 编辑被以 `422 validation_failed` 拒绝；`details[].field` 会标明已存储的字段 ID。不会发生部分编辑或部分发布。请在同一个 PATCH 中（或通过浏览器）修正该值后再重试。API 不会静默地豁免无效的已存储值，也不会丢弃无关字段。
