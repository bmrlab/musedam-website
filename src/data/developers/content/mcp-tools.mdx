## 调用约定

原有工具保留顶层参数；新增带参数工具使用 `params` 对象，内部字段保留 API 的 camelCase 命名。无参数工具传 `{}`。审批<MainlandOnly>和商品库</MainlandOnly>工具自动填入固定的 `service`，无需传入。API Key 和区域在连接中配置，国内默认无需 region，海外使用 `?region=overseas`。

修改素材使用 `score`（旧参数 `rating` 兼容，两者同时传入时 `score` 优先）；上传评分使用 `rating`，搜索使用 `ratings`。<MainlandOnly>商品库需要将 API Key 添加为协作者，并具备对应操作权限。</MainlandOnly>

```json
{
  "name": "musedam_upload_assets_async",
  "arguments": {
    "params": {
      "assets": [
        {
          "url": "https://example.com/video.mp4",
          "extension": "mp4"
        }
      ]
    }
  }
}
```

获取任务号后，使用 `musedam_upload_assets_task` 和 `{"params":{"taskId":"<taskId>"}}` 查询，直到 `SUCCESS` 或 `FAILED`。

[配置 MCP 连接](./mcp-connect)

仅管理员类型 API Key 可调用，权限不足时返回 `50083`。 上述权限限制适用于团队成员、部门、部门成员和角色成员查询。
