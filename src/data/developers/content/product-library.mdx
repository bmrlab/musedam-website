## 快速接入

商品库 API 的服务地址为 `https://open.musedam.cc/api/product`。在此地址后添加接口路径，例如 `/products`。

1. 获取 MuseDAM API Key。
2. 请商品库管理员在「成员设置 → 添加成员」中，将该密钥添加为 API Key 协作者，并分配所需角色。
3. 从服务端调用接口，在请求头中携带 `Authorization: Bearer <key>`。

权限按密钥所属团队和协作者当前角色校验，请求参数不能切换商品库。

新添加的协作者默认为 `view_only`。按需要选择角色：

| 角色 | 可执行的操作 |
| --- | --- |
| `view_only` | 查看已发布商品。 |
| `usable` | 查看、分享和下载已发布商品。 |
| `editable` | 创建和编辑商品、访问草稿、发布及删除商品。 |
| `manage` | 管理全部资源，包括品牌、分类、信息模板及活动记录。 |

每个角色包含上一级角色的权限。后续示例中的资源 ID 需替换为实际值。

将 `your_api_key` 替换为已授权的 API Key，查询商品列表：

```bash
curl --request GET 'https://open.musedam.cc/api/product/products?page=1&pageSize=20' \
  --header 'Authorization: Bearer your_api_key'
```

请求成功时，`success` 为 `true`，`data` 为商品列表，`pagination` 为分页信息。列表为空时，先确认商品库中是否有当前角色可见的商品；`view_only` 和 `usable` 只能查看已发布商品。

## 请求与响应

所有请求均携带 `Authorization: Bearer <key>`；JSON 请求使用 `Content-Type: application/json`。接口表中的路径均相对上述服务地址。

JSON 接口使用以下结构。下载和导出成功时直接返回文件。

| 返回内容 | 读取方式 |
| --- | --- |
| 操作成功 | `success: true`，从 `data` 读取结果；`code`、`message` 为 `null`。 |
| 操作失败 | `success: false`，`data: null`；按 HTTP 状态码和 `code` 处理，不依赖 `message` 的文案。 |
| 参数校验失败 | 若响应包含 `details`，可按 `details[].field` 和 `details[].message` 修正字段。 |
| 请求追踪 | 保存 `requestId` 或响应头 `X-Request-Id`，用于排查问题。 |

普通列表使用 `page` 和 `pageSize`，在响应顶层返回 `pagination`。其中 `totalCount` 为总条数，`totalPages` 为总页数：

| 参数 | 默认值 | 范围 |
| --- | --- | --- |
| `page` | `1` | 从 `1` 开始的整数。 |
| `pageSize` | `20` | 正整数，超过 `100` 时按 `100` 处理。 |

```json
{
  "page": 1,
  "pageSize": 20,
  "totalCount": 42,
  "totalPages": 3
}
```

商品和素材可能在请求期间变为不可见，因此实际返回条数可能少于 `pageSize`，计数仍保留分页时的结果。单项资源不可见时返回 `404`。

需要持续同步商品时，请使用[游标同步](#cycle-protocol)，不要依靠普通页码列表。筛选参数见具体接口；普通查询会忽略未知参数，JSON 请求体会拒绝未知字段。

<details id="field-formats">
<summary>字段格式</summary>

| 字段 | 使用方式 |
| --- | --- |
| 数值型资源 ID | 正整数，最大 `2147483647`。 |
| 模板、分组、字段、版本 ID | 字符串，原样保存，不假定为 UUID。 |
| 素材 ID | 使用素材查询返回的 `id`（FilePath ID），不能替换成 AssetObject ID 或商品关联 ID。 |
| 分类 `iconAssetId` | 使用分类图标的标识符（CategoryIconAsset）。 |
| `size` | 十进制字符串或 `null`，避免大文件字节数丢失精度。 |
| 日期 | RFC 3339 字符串或 `null`；同步时间戳保留完整六位小数。 |
| 商品 SKU | API 字段名为 `spu`。 |

旧版或无法解析的商品媒体可能返回 `id: null`。有效的媒体引用不会被截断。预览和下载链接的使用方式见[媒体链接](#media-and-expiry)。

</details>

<details id="write-preconditions">
<summary>并发更新</summary>

读取品牌、分类、模板或商品时保存强 `ETag`（包括引号），更新、状态变更或删除时可放入 `If-Match`。返回 `412 precondition_failed` 时重新读取并核对；省略时后一次写入覆盖前一次。分享、历史和下载记录不使用 ETag。

</details>

<details id="atomic-create-replay">
<summary>创建与下载重试</summary>

创建资源可使用 `Idempotency-Key`。键按团队、API Key 和操作区分，最长 255 个字符，不能为空白或含控制字符。24 小时内用相同键和输入重试；更改输入返回 `409 idempotency_key_reused`。资源创建重放首次非媒体结果，媒体按当前权限重建。下载重试只复用业务记录，仍重新鉴权并传输当前文件。

</details>

<details id="error-catalog">
<summary>请求限制与失败处理</summary>

请求体最多 1 MiB。未知 JSON 字段被拒绝；普通查询忽略未知参数，历史和同步查询另有严格校验。

| 返回结果 | 处理方式 |
| --- | --- |
| 401 / 403 | 检查密钥、协作者角色及资源可见性。 |
| 404 | 资源不存在、已删除或不可访问，核对 ID。 |
| 422 `validation_failed` | 修正输入；若有 `details`，读取 `field` 和 `message`。 |
| 409 `sku_in_use` / `name_in_use` | 修改冲突的 SKU 或名称；软删除商品的 SKU 仍被占用。 |
| 409 `mutation_response_unavailable` | 变更已提交或重放，按 `mutationOutcome` 核对；不要盲目重新创建。 |
| 503 `write_conflict` | 变更已回滚，按 `Retry-After: 1` 等待后重试。 |
| 413 | 缩小请求体或下载数量/大小。 |

通过响应头 `X-Request-Id` 或 JSON 中的 `requestId` 排查请求。下载错误含 `mutationOutcome` 时，记录已经提交，重试沿用原幂等键。

</details>

## 分类

<details id="category-rules">
<summary>分类树与删除</summary>

同级名称必须唯一，父分类必须属于同一品牌。分类最多 10 级，每个品牌最多 5000 个未删除节点。`sortOrder` 是从零开始的同级位置；创建或移动时省略则追加，同父级更新时省略则保持位置。改名或移动会更新后代路径。

创建时，只有商品库默认模板未绑定品牌或已绑定当前品牌，才添加直接模板绑定；否则仍创建成功，按祖先分类、品牌、商品库默认模板查找。删除会软删除整棵子树；其中有未删除商品时返回 `409 category_has_products`，不执行删除。

</details>

**接口路径**：/categories

| - | CategoryCreate | 是 | JSON 请求体：application/json |

**CategoryCreate参数说明**：

不接受未定义字段。

| 字段名 | 类型 | 必填 | 描述 |

## 信息模板

<details id="template-groups">
<summary>分组 groups</summary>

`groups` 包含 1–200 个分组，一个模板的字段总数最多为 200。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 现有分组必填，1–128 个字符，必须属于本模板；新分组不传。 |
| `name` | string | 必填，1–128 个字符，去除首尾空白。 |
| `fields` | array | 必填，分组中的字段，见下表。 |

现有分组保持原有顺序，新分组按提交顺序追加。分组不接受 `sortOrder` 或 `isDefault`。默认分组由服务器指定，不能删除。

</details>

<details id="template-fields">
<summary>字段 fields</summary>

新字段必须提供 `key`、`name` 和 `type`。更新现有字段时必须传 `id`。类型不变时，省略的属性保留原值，`sortOrder` 除外；改变 `type` 时，`config` 会按目标类型迁移，必要时须显式提供新配置。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 现有字段必填，1–128 个字符，必须属于当前分组；新字段不传。 |
| `key` | string | 新字段必填，1–64 个字符，须为唯一的有效标识符；已有字段不能修改。 |
| `name` | string | 新字段必填，1–128 个字符。 |
| `type` | string | 新字段必填，支持的类型见下方配置表。 |
| `required` | boolean | 可选；新字段默认为 `false`。 |
| `placeholder` | string 或 null | 可选，最多 255 个字符；新字段默认为 `null`。 |
| `sortOrder` | integer | 可选，同组内唯一的非负整数；省略时使用字段在数组中的位置。 |
| `config` | object | 按字段类型填写，见下方配置表；新字段省略时使用 `{}`，但仍须满足该类型的配置要求。 |
| `typeChangeConfirmed` | boolean | 可选；允许但需要确认的类型变更须传 `true`。 |

创建时会自动加入名称、SKU 和主图三个受保护字段，因此最多可新增 197 个自定义字段。第一个分组的自定义字段排列在这三个字段之后，传入的 `sortOrder`（省略时为数组位置）会增加 3。替换定义时须保留这些字段的 `id`，以及类型、必填标记和配置。字段不能移到其他分组。

新字段只能是自定义字段，不能使用保留的系统 key。`isSystemField` 和 `systemKey` 不能用于创建或重新分配系统身份；更新时保留原值。未知的分组或字段属性会被拒绝。

</details>

<details id="field-configuration">
<summary>字段配置 config</summary>

配置由字段的 `type` 决定。例如，文本字段使用 `{}`，货币和选项字段需要额外配置。

| 字段类型 | config 配置 |
| --- | --- |
| `text`、`textarea`、`email`、`phone`、`url`、`color`、`date`、`dateRange` | 使用 `{}`，不接受其他配置。 |
| `number` | 可选 `unit`，字符串。 |
| `currency` | 必填 `code`、`symbol`（非空字符串）和 `decimals`（0–4 的整数）。 |
| `richtext` | 必填 `mode`，取值为 `html` 或 `delta`。 |
| `select`、`radio`、`checkbox` | 必填非空 `options` 数组。每项见下表，`value` 不得重复。 |
| `image`、`file` | 可选 `maxCount`（大于等于 1 的整数）、`maxSizeMB`（大于 0 的数字）和 `accept`（字符串数组）。 |

每个 `options` 元素包含：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `value` | string | 必填，非空，选项的唯一值。 |
| `label` | string | 必填，非空，显示名称。 |
| `sortOrder` | integer | 必填，非负整数。 |
| `archived` | boolean | 可选，是否归档该选项。 |

系统字段的可用配置是 `customPlaceholder`（可选字符串，最多 255 个字符）；品牌、分类系统字段不接受自定义选项。受保护系统字段的配置不能变更。

空配置和系统配置拒绝未知属性；其他配置及选项会移除未知属性。完整机器可读定义可下载 [OpenAPI JSON](/assets/developers/product-library/openapi.json)。

</details>

<details id="template-definition">
<summary>返回的模板定义</summary>

模板详情的 `groups` 和商品的 `templateDefinition.groups` 均包含分组与字段。商品返回的是创建时固定的版本，后续模板修改或删除不会改变它；未绑定模板时，`templateDefinition` 可为 `null`。

分组固定返回 `id`、`name`、`fields`，以及以下只读属性：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `isDefault` | boolean | 是否为默认分组。 |
| `sortOrder` | integer | 分组顺序。 |

每个字段固定返回 `id`、`key`、`name`、`type`、`required`、`placeholder`、`sortOrder`、`config`，以及以下属性；不返回写入参数 `typeChangeConfirmed`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `isSystemField` | boolean | 是否为系统字段。 |
| `systemKey` | string 或 null | 系统身份：`name`、`sku`、`brand`、`category`、`description`、`mainImage`；自定义字段为 `null`。 |

`placeholder` 可为 `null`。配置中的媒体引用会返回安全的预览信息，不包含存储路径或凭据。读取商品的固定模板定义不需要 `templates:read` 权限。

</details>

<details id="fields-Template">
<summary>Template 返回字段</summary>

| 字段名 | 类型 | 描述 |
| - | - | - |
| id | String | 资源 ID。最短 1 个字符；最长 128 个字符 |
| name | String | 名称。 |
| description | String | 说明。可为 null |
| enabled | Boolean | 是否启用模板。 |
| isSystemDefault | Boolean | 是否为系统默认模板。 |
| isLibraryDefault | Boolean | 是否为商品库默认模板。 |
| createdAt | String | RFC 3339 时间字符串；保留完整精度。|
| updatedAt | String | RFC 3339 时间字符串；保留完整精度。|
| boundBrandIds | List&lt;Integer&gt; | 绑定的品牌 ID。每个元素：正整数 ID，最大 2147483647。 |
| boundCategoryIds | List&lt;Integer&gt; | 绑定的分类 ID。每个元素：正整数 ID，最大 2147483647。 |
| groups | List&lt;VersionGroup&gt; | 模板分组。嵌套字段：[模板分组与字段](#template-definition) |

</details>

## 商品

<details id="template-pins-and-field-values">
<summary>模板版本与自定义字段</summary>

商品创建时保存模板版本。读取 `templateDefinition` 解释 `templateFields`；后续模板变更或删除不影响这个版本，普通 PATCH 不能更换模板。`templateFields` 以固定版本中的字段 ID 为键，更新时浅合并；`null` 清空单个字段。

显式 `templateId` 优先；否则，有 `categoryId` 时依次查找分类、祖先分类、品牌和商品库默认模板。没有分类时只考虑商品库默认模板，即使传入了品牌。

| 字段类型 | 输入格式 |
| --- | --- |
| `number`、`currency` | JSON 数字 |
| `dateRange` | 起止日期字符串组成的有序数组 |
| `checkbox` | 选项值数组 |
| `image`、`file` | FilePath ID 数组，或 null |
| `richtext` | HTML 模式为字符串；delta 模式为 `{ "ops": [...] }` |

草稿可缺少必填值，但提交和合并后的字段仍须满足类型/选项规则；发布或编辑已发布商品会校验完整商品。一次写入的全部媒体引用合计最多 100 个，只接受本商品库现有的 FilePath ID。媒体列表省略时保留，`[]` 清空；未传 `coverAssetId` 时，首张 `imageAssetIds` 图片成为封面。

</details>

<details id="cycle-protocol">
<summary>同步与检查点</summary>

1. 首次使用 `sync=true`，省略 `updatedAfter`；增量周期传入上次完成的 `syncedUntil`。
2. 按商品 `id` 和 `updatedAt` 合并，保留较新版本。
3. 使用 `sync=true&cursor=...` 跟随 `nextCursor` 直到 null；即使 `data` 为空，也要继续。
4. 完成后原样保存 `syncedUntil`，不要改用最后一条商品的时间。

游标绑定密钥、角色、商品库、筛选条件和页大小；续页时不要改变它们。更换授权或筛选条件要开始新周期；范围扩大时重新全量同步。检查点和同步 `updatedAt` 保留完整六位小数，不要用 JavaScript Date 截断精度。每周期读取当前状态的 `[updatedAfter, syncedUntil)`，上界为首次请求时服务端时间减 30 秒；长事务仍可能影响完整性，不提供每次变更的事件流。

</details>

<details id="reconciling-removals">
<summary>清理已删除或不可见的商品</summary>

同步不会返回删除事件。定期将本地商品 ID 交给[可见性接口](#operation-checkProductVisibility)，`not_visible` 时移除本地副本。该接口不检查品牌、分类或搜索等业务筛选；若只维护筛选后的副本，须定期全量核对筛选结果，或同步全部可见商品后在本地筛选。

</details>

<details id="media-and-expiry">
<summary>预览与下载链接</summary>

展示商品媒体时使用 `previewUrl`。需要原文件时，检查 `downloadUrl`，或使用下一节的下载接口；能预览不等于有下载权限。

| 链接 | 返回条件 | 服务签发链接的有效期上限 |
| --- | --- | --- |
| 派生预览 | 具备相应查看权限 | 3600 秒 |
| 图片原图预览回退 | 仅适用于图片，`view_only` 也可能返回 | 300 秒 |
| `downloadUrl` | 关联可解析且可见，`usable` 或更高角色，同时具备 `products:read` 和 `products:download` | 300 秒 |

所有服务签发链接还受 API key 的到期时间限制。链接过期后重新获取商品数据，不要将签名 URL 当作素材 ID 保存。

<details id="product-media-fields">
<summary>封面、图片和关联素材返回哪些字段？</summary>

`cover` 是一个媒体对象，无封面时为 null；`images`、`relatedAssets` 为媒体对象数组。自定义图片/文件值可为数组或 null，未填写的字段可能省略。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | 整数或 null | 素材查询返回的 ID（FilePath ID），不是 AssetObject ID 或商品素材关联 ID |
| `name`、`mimeType` | 字符串或 null | 文件名、MIME 类型 |

| `downloadUrlExpiresAt` | 时间字符串或 null，可省略 | 下载地址的到期时间，RFC 3339 格式 |

<details>
<summary>链接缺失、旧版媒体和外部预览如何处理？</summary>

- 非图片素材只返回派生预览，原始 PDF、压缩包和文档不会作为预览回退。素材库素材查询和模板配置只包含预览。

### 获取或同步商品列表

**接口路径**：/products

**请求方式**：GET

**接口描述**：普通分页按 updatedAt/id 降序排序。sync=true 时按 (updatedAt,id) 升序排序，使用包含的下界和不包含的固定上界（PostgreSQL 时钟减 30 秒）。全量扫描时省略 updatedAfter；请持续跟随每个 nextCursor，即使 data 页为空。游标绑定 key/角色/商品库/筛选条件/pageSize/边界。仅在遍历完毕后原样保存 syncedUntil；按 id 和 updatedAt 进行重放/去重。持续时间超过 30 秒安全窗口的事务属于 v1 已接受的限制。见[同步说明](#cycle-protocol)。view_only/usable 仅可见已发布商品。

所需角色：所有协作者角色。

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 |
| - | - | - | - |
| page | Integer | 否 | 页码，正整数，默认 1；sync=true 时不可用。 |
| pageSize | Integer | 否 | 每页条数，正整数，默认 20，上限 100。 |
| search | String | 否 | 查询参数。去除首尾空白、不区分大小写的子串匹配：商品名称/spu，或素材库素材名称。 |
| brandId | Integer | 否 | 查询参数。按本商品库内的品牌 ID 筛选。正整数 ID，最大 2147483647。 |
| categoryId | Integer | 否 | 查询参数。按精确的分类 ID 筛选，不包含其后代分类。正整数 ID，最大 2147483647。 |
| status | String | 否 | 查询参数。请求的商品状态；不会扩大角色可见范围。允许值：draft、published |
| sync | String | 否 | 查询参数。true 表示使用有界的键集同步；false 表示普通分页。见[同步说明](#cycle-protocol)。允许值：true、false；默认值："false" |
| updatedAfter | String | 否 | 查询参数。仅在 sync=true 时使用。包含的下界；RFC3339 格式，使用 Z 或时区偏移，0..6 位小数，日历日期/偏移须有效。请将 syncedUntil 作为字符串保存并复用。全量扫描时省略。格式：date-time |
| cursor | String | 否 | 查询参数。不透明的续页令牌，仅在 sync=true 时使用。绑定 key、角色、商品库、边界、筛选条件和每页条数。续页时省略其他参数，或重复传入等价的值。重复的同步参数会被拒绝。最短 1 个字符；最长 8,192 个字符 |

**响应参数**： `200`，`data`：List&lt;ProductSummary&gt;。 [字段说明](#fields-ProductSummary) 分页字段见[响应与分页](#wire-format-and-identifiers)。

**SyncPage**

| 字段名 | 类型 | 描述 |
| - | - | - |
| pageSize | Integer | 每页数量。最小值：1；最大值：100 |
| syncedUntil | String | PostgreSQL 时钟减 30 秒，在整个周期内固定。仅在 nextCursor 为 null 后原样保存此字符串。格式：date-time；须匹配 `^\d{4}-\d\d-\d\dT\d\d:\d\d:\d\d\.\d{6}Z$` |

### 创建草稿商品

**接口路径**：/products

**请求方式**：POST

**接口描述**：仅创建草稿。创建时解析并固定一个模板版本；模板字段依据该不可变定义进行校验。可关联同一商品库中现有的 FilePath ID；不支持上传、远程导入或回写到提供方。幂等重放会保留原始标量结果/ETag，并且仅对在当前同一槽位中仍然有效的原始媒体按当前权限重新投影。

## 下载

<details id="download-usage">
<summary>选择文件、导出与记录</summary>

先查询商品下载候选，将返回的 `key` 放入 `assetKeys`，或 URL 编码后用作单文件路径参数 `assetKey`；它不是 FilePath ID。原文件下载仅一个文件时返回该文件，多个文件时返回 ZIP。每次选择 1–100 个商品、最多 200 个文件、合计不超过 500 MiB。

导出使用 `kind: "export"`，格式为 xlsx（默认）、csv 或 json，不能传 `assetKeys`。`includeAssetUrls` 默认 true，导出的链接仍需要 Bearer 请求头；给免登录访客使用时应创建分享。`locale` 只影响系统标签和状态。

附件响应头 `X-Download-Record-Id` 是业务记录 ID。`requested` 仅表示请求已接受，不表示传输或本地保存完成。历史包含团队浏览器操作及其他 API Key 的操作；普通读取、预览和直接访问存储下载 URL 不计入历史。

### 下载原文件或导出商品

**接口路径**：/product-downloads

**请求方式**：POST

**接口描述**：返回一个原文件、所选原文件的 ZIP，或 XLSX/CSV/JSON 业务表格导出。需要 usable 及以上角色的当前读取和下载权限；usable 只能访问已发布商品。已接受的操作在交付前记入记录。导出链接默认指向需认证的单文件 GET URL；每次接受的提取有自己的业务记录。可选 Idempotency-Key 在 24 小时内保留一条记录，每次重试仍重新鉴权并传输当前内容。商品读取、预览和旧存储 downloadUrl 的访问不会由此操作记入记录。

所需角色：usable、editable 或 manage。

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 |
| - | - | - | - |
| Idempotency-Key | String | 否 | 可选请求头；同一键和输入在 24 小时内重试，详见[幂等重试](#atomic-create-replay)。 |
| - | ProductDownloadCreate | 是 | JSON 请求体：application/json |

**ProductDownloadCreate参数说明**：

assets 省略 assetKeys 时选择全部原文件，否则仅选择提供的当前 key。export 不接受 assetKeys，并生成本地化业务表格。format、includeAssetUrls 和 locale 仅影响导出；素材下载接受这些选项但不据此改变交付内容。导出默认包含需要 Bearer 认证的链接，绝不包含 API key 密钥。locale 影响系统标签和状态，不改变用户自定义标签或内容。

不接受未定义字段。

| 字段名 | 类型 | 必填 | 描述 |
| - | - | - | - |
| kind | String | 是 | 允许值：assets、export |
| productIds | List&lt;Integer&gt; | 是 | 最少 1 项；最多 100 项；每个 ID 为正整数，最大 2147483647。 |
| assetKeys | List&lt;String&gt; | 否 | 每个元素：最短 1 个字符；最长 256 个字符；最少 1 项；最多 200 项 |
| format | String | 否 | 允许值：xlsx、csv、json；默认值："xlsx" |
| includeAssetUrls | Boolean | 否 | 默认值：true |
| locale | String | 否 | 允许值：zh-CN、en-US、zh-TW、ja-JP、ko-KR、pt-BR、ru-RU、id-ID、fr-FR、it-IT、pl-PL、vi-VN、tr-TR、th-TH、de-DE、es-ES、hi-IN；默认值："zh-CN" |

**响应参数**： `200`。成功返回附件，响应体为文件字节；JSON 仅用于交付前的错误。

响应头：`Content-Disposition`、`X-Download-Record-Id`、`X-Idempotency-Replayed`

请求示例：

```bash
curl --request POST \
  'https://open.musedam.cc/api/product/product-downloads' \
  --header 'Authorization: Bearer your_api_key' \
  --header 'Content-Type: application/json' \
  --data-raw '{
  "kind": "export",
  "productIds": [
    40
  ],
  "format": "xlsx",
  "includeAssetUrls": true,
  "locale": "zh-CN"
}' \
  --output products.xlsx
```

### 下载一个商品原文件

**接口路径**：/products/&#123;id&#125;/download-assets/&#123;assetKey&#125;

**请求方式**：GET

**接口描述**：通过编码后的候选 key 获取当前商品的一个原文件。需要 Bearer 请求头以及当前读取/下载授权；URL 不含 API key 密钥。交付前创建业务记录。可选的 24 小时幂等机制与 POST 下载使用不同作用域，复用记录时仍重新鉴权并传输当前字节。

所需角色：usable、editable 或 manage。

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 |
| - | - | - | - |
| id | Integer | 是 | 路径参数。正的有符号 32 位资源 ID。正整数 ID，最大 2147483647。 |
| assetKey | String | 是 | 路径参数。对商品下载候选列表返回的选择 key 进行 URL 编码；它不是 FilePath 或 AssetObject ID。最短 1 个字符；最长 256 个字符 |
| Idempotency-Key | String | 否 | 可选请求头；同一键和输入在 24 小时内重试，详见[幂等重试](#atomic-create-replay)。 |

**响应参数**： `200`。成功返回附件，响应体为文件字节；JSON 仅用于交付前的错误。

响应头：`Content-Disposition`、`X-Download-Record-Id`、`X-Idempotency-Replayed`

请求示例：

示例使用下载候选 key p40:a2，URL 编码后为 p40%3Aa2。请使用您的下载候选列表返回的 key，它不是 FilePath 或 AssetObject ID。

```bash
curl --request GET \
  'https://open.musedam.cc/api/product/products/40/download-assets/p40%3Aa2' \
  --header 'Authorization: Bearer your_api_key' \
  --output product-asset.bin
```
