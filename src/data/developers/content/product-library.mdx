## 服务地址

商品库 API 的服务地址为 `https://open.musedam.cc/api/product`。在此地址后添加接口路径，例如 `/products`。

## 获取授权

1. 获取 MuseDAM API Key。
2. 请商品库管理员在「成员设置 → 添加成员」中，将该密钥添加为 API Key 协作者，并分配所需角色。
3. 从服务端调用接口，在请求头中携带 `Authorization: Bearer <key>`。

新添加的协作者默认为 `view_only`。按需要选择角色：

| 角色 | 可执行的操作 |
| --- | --- |
| `view_only` | 查看已发布商品。 |
| `usable` | 查看、分享和下载已发布商品。 |
| `editable` | 创建和编辑商品、访问草稿、发布及删除商品。 |
| `manage` | 管理全部资源，包括品牌、分类、信息模板及活动记录。 |

每个角色包含上一级角色的操作权限。具体接口的权限要求见[接口文档](./product-library-reference)。

## 发起第一次请求

将 `your_api_key` 替换为已授权的 API Key，查询商品列表：

```bash
curl --request GET 'https://open.musedam.cc/api/product/products?page=1&pageSize=20' \
  --header 'Authorization: Bearer your_api_key'
```

请求成功时，`success` 为 `true`，`data` 为商品列表，`pagination` 为分页信息。列表为空时，先确认商品库中是否有当前角色可见的商品；`view_only` 和 `usable` 只能查看已发布商品。
