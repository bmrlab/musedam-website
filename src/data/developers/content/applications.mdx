## 概述

提供第三方应用使用企业开放API接口的能力。第三方应用需要企业管理员进行启用授权后，可通过appId和appSecretKey管理API密钥，并使用获取到的API密钥调用开放接口（详见"核心API接口"章节）。

## 基础信息

### 请求路径

- **生产环境**：https://open.musedam.cc/api/apps
- **海外环境**：https://open.musedam.ai/api/apps

### 认证方式

采用 **HTTP Basic Authentication**认证机制：

- 将appId和appSecretKey以`appId:appSecretKey`格式组合并进行base64编码
- 在HTTP请求头中添加：`Authorization: Basic [base64编码结果]`
- 所有应用相关请求必须包含此认证信息

**认证示例:**

假设您获取到的凭证为：

- appId: `test_app_123`
- appSecretKey: `s3cr3t_k3y_456`

**认证步骤：**

1. 组合appId和appSecretKey：`test_app_123:s3cr3t_k3y_456`
2. 对组合字符串进行base64编码：`dGVzdF9hcHBfMTIzOnMzY3IzdF9rM3lfNDU2`
3. 在HTTP请求头中添加认证信息：

   ```text
   Authorization: Basic YOUR_BASE64_APP_CREDENTIALS
   ```

> **重要提示**：appId和appSecretKey需向museDAM申请获取。请联系您的museDAM客户代表获取访问凭证。

### 获取API key

**接口地址**: `/exchange-api-key`

**请求方式**: POST

**请求体:**

```text
{
    "orgId":185
}
```

**响应结果**:

```json
{
    "code": 0,
    "message": "OK",
    "result": {
        "apiKey": "YOUR_API_KEY",
        "expiresAt": "2055-08-19 16:13:25",
        "org": {
            "id": 185,
            "name": "示例团队",
            "orgNo": "M000001",
            "orgFeeType": 4
        }
    },
    "traceId": "17555988913681722512"
}
```

请求示例：

```bash
curl --location --request POST 'https://open.musedam.cc/api/apps/exchange-api-key' \
--header 'Authorization: Basic YOUR_BASE64_APP_CREDENTIALS' \
--header 'Content-Type: application/json' \
--data-raw '{
    "orgId":185
}'
```

### 刷新 API Key

**接口地址**: `/refresh-api-key`

**请求方式**: POST

**请求体:**

```text
{
    "oldApiKey": "YOUR_API_KEY"
}
```

**响应结果**:

```json
{
    "code": 0,
    "message": "OK",
    "result": {
        "apiKey": "YOUR_API_KEY",
        "expiresAt": "2055-08-19 18:22:18"
    },
    "traceId": "17555989381206489704"
}
```

请求示例：

```bash
curl --location --request POST 'https://open.musedam.cc/api/apps/refresh-api-key' \
--header 'Authorization: Basic YOUR_BASE64_APP_CREDENTIALS' \
--header 'Content-Type: application/json' \
--data-raw '{
    "oldApiKey": "YOUR_API_KEY"
}'
```

### 撤销 API Key

**接口地址**: `/revoke-api-key`

**请求方式**: POST

**请求体:**

```text
{
    "apiKey": "YOUR_API_KEY"
}
```

**响应结果**:

```json
{
    "code": 0,
    "message": "OK",
    "result": true,
    "traceId": "17555989381206489704"
}
```

请求示例：

```bash
curl --location --request POST 'https://open.musedam.cc/api/apps/revoke-api-key' \
--header 'Authorization: Basic YOUR_BASE64_APP_CREDENTIALS' \
--header 'Content-Type: application/json' \
--data-raw '{
    "apiKey": "YOUR_API_KEY"
}'
```
