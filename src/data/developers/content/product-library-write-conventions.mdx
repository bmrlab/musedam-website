## 写入前置条件

所有路径使用 Base URL `https://open.musedam.cc/api/product`。每个操作的权限由当前 API Key 协作者角色决定。在请求中提供团队、商品库、操作者或操作白名单，不能增加权限。

更新前先读取资源并保存强 `ETag`，在 PATCH、状态变更或 DELETE 时通过 `If-Match` 原样发送。过期或弱标签返回 `412 precondition_failed`，不会修改资源。`*` 或包含当前强标签的逗号分隔列表同样视为匹配。省略该请求头时，后一次写入覆盖前一次。分享、历史和有记录的下载不使用 ETag 或 If-Match。

## 创建与幂等重试

资源创建接受可选的 `Idempotency-Key`，按团队、API key 和操作划定作用域，保留 24 小时。值不能为空白，最多 255 个字符，不得包含 ASCII 控制字符。创建结果不确定时，请使用相同幂等键和输入重试。同一键对应的规范化输入不同，返回 `409 idempotency_key_reused`。

重放保留首次成功的非媒体结果和 ETag，即使资源之后已被修改。媒体 URL 会在重新检查当前权限、可见性和关联关系后签发。不能通过重放恢复已删除或不可见的商品，新增的素材关联也不会进入首次结果。新的逻辑操作才使用新的幂等键。

## 部分更新

省略的字段保留原值，显式 `null` 仅清空允许为空的字段。商品 `templateFields` 按自定义字段 ID 浅合并，null 清空对应值。模板 `groups` 一旦提供即替换完整定义，必须保留现有分组和字段 ID，包括受保护的系统字段。未知 JSON 属性会被拒绝。

## 品牌

品牌写入需要 `manage` API Key 协作者。创建接受 `name`、`description` 和 `logoUrl`，PATCH 接受其中的非空子集。名称去除首尾空白后不能为空，最多 128 个字符；描述可为 null，最多 512 个字符。Logo 引用必须使用允许的存储/CDN 主机及不含内嵌凭据的 HTTP(S) 地址，查询签名在存储前移除。写入不会上传或远程导入素材。

品牌响应省略 `logoUrl`，返回 `id`、`name`、`code`、`description`、`website`、`sortOrder`、`isEnabled`、`createdAt` 和 `updatedAt`。名称不要求唯一；商品库内唯一的编码由服务端生成，客户端不能设置。编码冲突重试耗尽时返回 `409 code_in_use`。

仍有未删除的分类或商品引用品牌时，删除返回 `409 brand_has_dependents`。请先调整或移除依赖。

## 写入结果与恢复

已回滚的锁冲突返回 `503 write_conflict` 和 `Retry-After: 1`。等待后重试，创建操作保留相同幂等键，并按需刷新过期的前置条件。

变更已提交但响应无法准备时，返回 `409 mutation_response_unavailable`、`success: false`、`data: null`，以及 `mutationOutcome: committed`（重放时为 `replayed`）。不会返回 ETag 或媒体 URL。此时变更没有回滚，请通过有权限的读取或原始幂等键核对，避免盲目重复操作。

已接受的下载和导出可能返回具体的准备或交付错误，并附带 `mutationOutcome`。重试该操作时保留原始幂等键。`requested` 只表示已接受，不表示传输完成或本地文件已保存。

## 排查错误

`401` 或 `403` 应修正 API key 或协作者角色；`422` 应检查 `details[].field` 并修正输入。保留 `X-Request-Id` 或 JSON 中的 `requestId` 以便排查，不记录密钥和签名媒体 URL。参见[错误目录](./product-library-reference#error-catalog)和[接口文档](./product-library-reference)。
