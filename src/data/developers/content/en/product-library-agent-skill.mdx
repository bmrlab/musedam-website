Give your AI assistant the [documentation index](https://www.musedam.cc/en-US/developers/llms.txt), the [Product Library quick start in Markdown](https://www.musedam.cc/en-US/developers/markdown/product-library.md), and the [OpenAPI contract](/assets/developers/product-library/openapi.json). The page toolbar can copy a ready-to-use prompt or the current document as Markdown. These resources are public and do not require repository access.

&#62; Read the Product Library quick start and API documentation before implementation. Use https://open.musedam.cc/api/product as the API Base URL. Determine the required collaborator role from the requested operation, and use only documented endpoints and fields. For synchronization, follow the cursor protocol and reconcile visibility. Keep credentials in secure local or server-side configuration.

## Configure credentials and permissions

Use an existing MuseDAM API key. Ask a Product Library Manager to add it as an API Key Collaborator through **Member Settings → Add Members**. Its initial role is `view_only`; choose a role for the intended operations. Product Library does not issue keys, and each role defines its operation permissions.

Send the API key in the `Authorization: Bearer <key>` header from your server. See [getting access](./product-library#authentication-and-scope).
