## Using this reference

This reference covers all 31 operations across 17 paths. Append the paths below to the Base URL (`https://open.musedam.cc/api/product`).

[Download OpenAPI JSON](/assets/developers/product-library/openapi.json) · [Product Library overview](./product-library) · [Integration examples](./product-library-examples)

Send `Authorization: Bearer <key>` from your server over HTTPS. The key must be added as a Product Library collaborator; its current role determines access. See [authentication and scope](./product-library#authentication-and-scope).

JSON responses use `success`, `data`, `code`, `message` and `requestId`; lists also include `pagination`. Successful downloads and exports return attachments.

Request bodies are limited to 1 MiB, including GET requests. v1 does not provide bulk writes, multipart upload, webhooks or a browser CORS/rate-limit contract. See [write conventions](./product-library-write-conventions) for concurrency, retries and error handling.

## Download originals or export products

**Endpoint**: `/product-downloads`

**Method**: POST

**Description**: Returns one original, a ZIP of selected originals, or an XLSX/CSV/JSON business-table export.
