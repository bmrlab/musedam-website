## Calling conventions

Existing tools retain their top-level arguments. New tools with inputs accept a `params` object with camelCase API fields; no-input tools accept `{}`. Do not supply `service`: each approval<MainlandOnly> and product</MainlandOnly> tool fixes it internally. Configure API Key and region on the connection; China is the default, overseas uses `?region=overseas`.

Use `score` for asset modifications (`rating` is a compatibility alias; `score` wins). Uploads use `rating`, searches use `ratings`.<MainlandOnly> Product Library requires API Key collaborator access and operation permissions.</MainlandOnly>

```json
{
  "name": "musedam_upload_assets_async",
  "arguments": {
    "params": {
      "assets": [
        {
          "url": "https://example.com/video.mp4",
          "extension": "mp4"
        }
      ]
    }
  }
}
```

Then query `musedam_upload_assets_task` with `{"params":{"taskId":"<taskId>"}}` until `SUCCESS` or `FAILED`.

[Configure MCP](./mcp-connect)

Only administrator-type API Keys may call this endpoint. Insufficient permissions return `50083`. This restriction applies to team members, departments, department members and role members.
