## Get processed public links for original assets

**Prerequisite:** DAT must be enabled.

**Endpoint:** `/processed-public-links`

**Method:** POST

**Request parameters:** `publicLinkProcessReq`

| Field | Type | Required | Description |
|-|-|-|-|
| assetIds | List&lt;Long> | Yes | Asset IDs (assetId) |
| w | Integer | No | Target width in pixels, 1–6000; values exceeding the original width have no effect |
| h | Integer | No | Target height in pixels, 1–6000; values exceeding the original height have no effect |
| mode | String | No | Resize mode; defaults to fit. fit: preserve aspect ratio; crop: center crop |
| q | Integer | No | Output quality, 1–100; defaults to 80 |
| f | String | No | Output format: jpg / png / webp; omit to retain the original format |
| bg | String | No | Background fill color in HEX without #, such as FFFFFF |

**mode values:**

| Value | Description |
|-|-|
| fit | Scale by the longer edge, preserving aspect ratio and the full image |
| crop | Center crop to the target dimensions |

**Response:** `Map<Long, String>`

- Key：assetId  
- Value: The processed public URL for the original asset, or `""` if no public link exists or the asset is missing.

## Retrieve asset derivatives in bulk

**Prerequisite:** Asset derivatives must be enabled for the team; otherwise, the endpoint returns an error.

**Endpoint:** `/asset-derivative-versions`

**Method:** `POST`

**Request parameters:** `assetDerivativeInfoReq`

| Field | Type | Required | Description |
|-|-|-|-|
| assetIds | List&lt;Long> | Yes | Asset IDs, matching `id` / `assetIds` elsewhere in the Open API |

**Response:** `Map<Long, List<EnterpriseAssetDerivativeVersionDTO>>`

- **Key:** An asset ID from the request
- **Value:** All derivative versions under **enabled** rules; `[]` if none exist or the asset is missing

**`EnterpriseAssetDerivativeVersionDTO` fields:**

| Field | Type | Description |
|-|-|-|
| size | Long | File size in bytes |
| width | Integer | File width in pixels |
| height | Integer | File height in pixels |
| accessUrl | String | Download URL; populated only when `generateStatus = 1` (success) |
| publicUrl | String | Derivative public URL; available when public links are enabled for the rule and the link has been generated |
| internalName | String | Internal derivative rule name |
| displayName | String | Derivative rule display name |
| generateStatus | Integer | Generation status; see below |
| name | String | Asset name |

**generateStatus values:**

| Value | Description |
|-|-|
| 0 | Processing |
| 1 | Success |
| 2 | Failed |
| 3 | Queued |

**Example request:**

```bash
curl --location --request POST 'https://open.musedam.ai/api/muse/asset-derivative-versions' \
--header 'Authorization: Bearer your_api_key' \
--header 'Content-Type: application/json' \
--data-raw '{
    "assetIds": [1234567890, 9876543210]
}'
```

**Example response:**

```json
{
    "code": "0",
    "message": "OK",
    "result": {
        "1234567890": [
            {
                "size": 204800,
                "width": 1920,
                "name":"xxx",
                "height": 1080,
                "accessUrl": "https://example.com/download/xxx.jpg?token=...",
                "publicUrl": "https://example.com/public/xxx.jpg",
                "internalName": "web_preview",
                "displayName": "Web preview",
                "generateStatus": 1
            }
        ],
        "9876543210": []
    },
    "traceId": "17561978534182325498"
}
```

**Notes:**

- Returns derivatives under **enabled rules**, regardless of the display toggle on the asset details page.
- `accessUrl` is a signed download URL with an expiry. `publicUrl` requires public link generation to be enabled for the rule and a public read address to have been generated for the derivative.
