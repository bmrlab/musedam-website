`POST /api/product/products` 需要 `products:create`，返回 `201`。
`PATCH /api/product/products/{id}` 需要 `products:update`，返回 `200`。兩者都會在標準信封中返回商品詳情 DTO，並返回強 `ETag`。
PATCH 接受可選的 `If-Match`；過期的校驗值返回 `412 precondition_failed`。
POST 接受可選的 `Idempotency-Key`，採用共享的 24 小時、團隊/key/操作範圍。

請求體僅接受以下屬性：

| 屬性                    | 值                                | 創建時默認值 / PATCH 行為                                                          |
| ----------------------- | --------------------------------- | ---------------------------------------------------------------------------------- |
| `name`                  | 字符串，最多 255 個字符           | 草稿名稱為空 / 省略時保留                                                          |
| `spu`                   | 最多 64 個字符的字符串，或 null   | Null；僅含空白時裁剪為 null / 省略時保留                                           |
| `description`           | 字符串或 null                     | Null / 顯式 null 時清空                                                            |
| `brandId`, `categoryId` | 正整數或 null                     | Null / 省略時保留；結果中的分類必須屬於結果中的品牌                                |
| `ownerUserId`           | 同一團隊成員 ID 或 null           | 無負責人 / 省略時保留；顯式 null 時清空                                            |
| `templateId`            | 同一商品庫中有效的模板 ID 或 null | 選擇此模板；null/省略時使用下方的解析規則。PATCH 中會被拒絕                        |
| `templateFields`        | 以自定義字段 ID 為鍵的對象        | 空 / 淺合併；null 值清空對應的單個字段                                             |
| `coverAssetId`          | 素材庫素材 ID 或 null             | 無顯式封面 / null 時清空封面                                                       |
| `imageAssetIds`         | 素材庫素材 ID 數組                | 空 / 省略時保留圖片；空數組時清空；除非提供了 coverAssetId，否則第一張圖片成為封面 |
| `relatedAssetIds`       | 素材庫素材 ID 數組                | 空 / 省略時保留關聯（包括舊版鏈接）；空數組時清空                                  |

創建時，顯式指定的有效 `templateId` 優先。當其省略或為 null 時，提供非 null 的 `categoryId` 會啓用分類/祖先分類綁定，其次是該分類所屬品牌的綁定，最後是商品庫默認模板。當 `categoryId` 省略或為 null 時，即使提供了 `brandId`，也只會考慮商品庫默認模板。如果未解析到任何模板，商品將沒有模板。

創建始終生成草稿。Status 和 templateVersionId 不是請求體屬性。對已發佈商品執行 PATCH 還額外需要 `products:publish`，會保持其發佈狀態，並校驗完整的結果商品。提交前的校驗或事務失敗會將標量變更和媒體關聯一併回滾。已提交的變更仍可能無法返回響應，請按[寫入恢復規則](./product-library-write-conventions#write-outcomes-and-audit-durability)處理。

草稿中可以缺少必填字段。提交的值以及合併後的值仍必須具有有效的類型和枚舉選項。日期和日期範圍值必須是真實存在的日曆日期（包括有效的閏日）；日期範圍必須有序。現有的 datetime 和時區格式仍受支持。圖片/文件類自定義字段接受素材庫素材 ID 數組或 null，並遵守固定版本中該字段的數量、大小和可接受類型配置。一個請求最多可包含 100 個素材引用（總計），包括封面、圖片、關聯素材和自定義字段。它不能上傳、下載或同步素材。圖片槽位要求使用圖片素材。

自定義值使用現有商品固定的不可變定義，即使在模板被編輯或軟刪除之後也是如此。固定版本缺失或不匹配時，會以通用內部錯誤失敗。新商品會固定所選或解析出的模板的最新版本。PATCH 無法遷移模板。

`PATCH /api/product/products/{id}/status` 僅接受
`{"status":"draft"}` 或 `{"status":"published"}`，並且始終同時需要
`products:update` 和 `products:publish`，即使請求的狀態與當前狀態相同。它返回商品詳情 DTO 和新的強 ETag。
`If-Match` 是可選的；過期的校驗值返回 `412`，且不會修改該行。發佈會校驗完整的固定版本定義，包括必填的系統字段和自定義字段、自定義類型/選項，以及已存儲圖片/文件的可用性和配置限制。缺少字段時返回 `422` 並附帶字段詳情。默認情況下，名稱、SKU 和封面為必填；固定版本的模板可以覆蓋系統字段的必填要求。首次發佈會設置 `publishedAt`；重復發佈會保留該值。恢復為草稿會清空 `publishedAt`，並允許之後進行不完整的草稿編輯。

`DELETE /api/product/products/{id}` 需要 `products:delete`；已發佈商品還額外需要 `products:publish`。它會軟刪除該行，並返回 `200`、`data: {"id": 123}` 以及新的強 ETag。可選的 `If-Match` 使用相同的校驗規則。重復刪除返回 `404`。

校驗失敗返回 `422 validation_failed`，並可附帶包含 `field` 和 `message` 的 `details` 條目。外部/已刪除/無效的引用屬於校驗錯誤。重復的 SKU（包括已軟刪除的商品）返回 `409 sku_in_use`。外部、已刪除或不存在的商品 ID 返回 `404`。API 的創建者/更新者歸屬獨立於人工負責人；key 的創建者絕不會自動成為商品負責人（Product Owner）。

冪等重放會保留原始的非媒體字段和原始 ETag。它存儲的是原始媒體 ID，絕不存儲存儲 URL 或簽名。重放的媒體僅限於那些仍存在於相同當前關聯槽位中的原始 ID；較新的關聯不會進入原始結果。當前 key 的權限、商品可見性和文件有效性會被重新檢查。下載屬性仍同時需要商品讀取和商品下載權限。已刪除/不可見的商品不能通過已存儲的結果恢復。

結構化自定義值中的嵌套媒體遵循相同的投影規則。快照會記錄已授權的文件/對象 ID，不包含素材快照和存儲憑據；響應會重新投影這些引用。重放會保留原始的業務文本和鏈接值，同時移除不再與該自定義字段關聯的嵌套媒體。標量文本和 URL 字段仍屬於普通業務數據。

PATCH 和發佈會依據固定版本定義校驗整個結果商品。因此，瀏覽器端遺留的值（例如無效的 URL 或郵箱）可能導致一次無關的 API 編輯被以 `422 validation_failed` 拒絕；`details[].field` 會標明已存儲的字段 ID。不會發生部分編輯或部分發佈。請在同一個 PATCH 中（或通過瀏覽器）修正該值後再重試。API 不會靜默地豁免無效的已存儲值，也不會丟棄無關字段。
