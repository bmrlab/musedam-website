## 調用約定

原有工具保留頂層參數；新增帶參數工具使用 `params` 對象，內部字段保留 API 的 camelCase 命名。無參數工具傳 `{}`。審批和商品庫工具自動填入固定的 `service`，無需傳入。API Key 和區域在連接中配置，國內默認無需 region，海外使用 `?region=overseas`。

修改素材使用 `score`（舊參數 `rating` 兼容，兩者同時傳入時 `score` 優先）；上傳評分使用 `rating`，搜索使用 `ratings`。商品庫需要將 API Key 添加為協作者，並具備對應操作權限。

```json
{
  "name": "musedam_upload_assets_async",
  "arguments": {
    "params": {
      "assets": [
        {
          "url": "https://example.com/video.mp4",
          "extension": "mp4"
        }
      ]
    }
  }
}
```

獲取任務號後，使用 `musedam_upload_assets_task` 和 `{"params":{"taskId":"<taskId>"}}` 查詢，直到 `SUCCESS` 或 `FAILED`。
