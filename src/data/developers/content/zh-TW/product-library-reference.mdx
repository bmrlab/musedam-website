## 查找接口

首次接入請先閱讀[快速接入](./product-library)，完成授權並發起第一次請求。本頁按資源列出接口的參數、請求與響應範例。

服務地址：`https://open.musedam.cc/api/product`。在服務地址後添加接口路徑即可調用；範例中的 `your_api_key` 和資源 ID 需替換為實際值。

品牌寫入與刪除說明見[品牌操作](./product-library-write-conventions#brands)。

### 獲取品牌列表

**接口路徑**：/brands

**請求方式**：GET

**接口描述**：返回公開元數據，按 sortOrder 再按 id 排序。不包含原始 logo URL。

所需角色：view_only、usable、editable 或 manage。

**請求參數**：

| 參數名 | 類型 | 必填 | 描述 |
| - | - | - | - |
| page | Integer | 否 | 查詢參數。普通分頁頁碼。sync=true 時不允許使用。偏移量過大導致整數溢出時會被拒絕。最小值：1；默認值：1 |
| pageSize | Integer | 否 | 查詢參數。每頁條數；超過 100 的值會被限制為 100。非正數/非整數值會被拒絕。最小值：1；默認值：20 |

**響應參數**：

| 字段名 | 類型 | 描述 |
| - | - | - |
| success | Boolean | 請求成功時為 true。 |
| data | List&lt;Brand&gt; | 返回的數據，字段見下表。 |
| code | String | 請求成功時為 null。 |
| message | String | 請求成功時為 null。 |
| requestId | String | 請求標識符，UUID 格式。 |
| pagination | Page | 分頁信息，字段見下表。 |

**Brand參數說明**：

| 字段名 | 類型 | 描述 |
| - | - | - |
| id | Integer | 資源 ID。最小值：1；最大值：2,147,483,647 |
| name | String | 名稱。 |
| code | String | 編碼。 |
| description | String | 說明。可為 null |
| website | String | 網站地址。可為 null |
| sortOrder | Integer | 排序值。 |
| isEnabled | Boolean | 是否啓用。 |
| createdAt | String | RFC 3339 UTC 時間戳字符串。請保留全部小數位；同步中商品的 updatedAt 使用六位小數。格式：date-time |
| updatedAt | String | RFC 3339 UTC 時間戳字符串。請保留全部小數位；同步中商品的 updatedAt 使用六位小數。格式：date-time |

**Page參數說明**：

| 字段名 | 類型 | 描述 |
| - | - | - |
| page | Integer | 當前頁碼。最小值：1 |
| pageSize | Integer | 每頁數量。最小值：1；最大值：100 |
| totalCount | Integer | 總數量。最小值：0 |
| totalPages | Integer | 總頁數。最小值：0 |

成功響應：200。

響應頭：`Cache-Control`、`X-Request-Id`

[查看錯誤處理](./product-library-write-conventions#error-catalog)。

**示例**：

請求示例：

```bash
curl --request GET \
  'https://open.musedam.cc/api/product/brands?page=1&pageSize=20' \
  --header 'Authorization: Bearer your_api_key'
```

### 創建品牌

**接口路徑**：/brands

**請求方式**：POST

**接口描述**：創建品牌；允許名稱重復，code 由服務端生成。logo 主機限制請參閱 BrandCreate。

所需角色：manage。

**請求參數**：

| 參數名 | 類型 | 必填 | 描述 |
| - | - | - | - |
| Idempotency-Key | String | 否 | 請求頭參數。可選，非空白且不含 ASCII 控制字符。作用域為團隊、key 和創建操作，有效期 24 小時。相同的規範化載荷會重放 201 及原始標量結果/ETag；載荷變更則返回 409。商品媒體會依據當前授權和有效的原始同槽位關聯重新投影。最短 1 個字符；最長 255 個字符 |
| - | BrandCreate | 是 | JSON 請求體：application/json |

**BrandCreate參數說明**：

不接受未定義字段。

| 字段名 | 類型 | 必填 | 描述 |
| - | - | - | - |
| name | String | 是 | 校驗前會去除首尾空白。最短 1 個字符；最長 128 個字符 |
| description | String | 否 | 最長 512 個字符；可為 null |
| logoUrl | String | 否 | null/空值表示清除。僅支持 HTTP(S)，不得包含憑據，且須為允許列表中的 MuseDAM CDN 或已配置的存儲主機；存儲前會移除 query 和 fragment。不支持上傳；讀取時不會返回。最長 512 個字符；可為 null |

**響應參數**：

| 字段名 | 類型 | 描述 |
| - | - | - |
| success | Boolean | 請求成功時為 true。 |
| data | Brand | 返回的數據，字段見下表。 |
| code | String | 請求成功時為 null。 |
| message | String | 請求成功時為 null。 |
| requestId | String | 請求標識符，UUID 格式。 |

**Brand參數說明**：

| 字段名 | 類型 | 描述 |
| - | - | - |
| id | Integer | 資源 ID。最小值：1；最大值：2,147,483,647 |
| name | String | 名稱。 |
| code | String | 編碼。 |
| description | String | 說明。可為 null |
| website | String | 網站地址。可為 null |
| sortOrder | Integer | 排序值。 |
| isEnabled | Boolean | 是否啓用。 |
| createdAt | String | RFC 3339 UTC 時間戳字符串。請保留全部小數位；同步中商品的 updatedAt 使用六位小數。格式：date-time |
| updatedAt | String | RFC 3339 UTC 時間戳字符串。請保留全部小數位；同步中商品的 updatedAt 使用六位小數。格式：date-time |

成功響應：201。

響應頭：`Cache-Control`、`X-Request-Id`、`ETag`

[查看錯誤處理](./product-library-write-conventions#error-catalog)。

409：品牌 code 衝突、冪等鍵被復用，或變更已提交但響應不可用。

**示例**：

請求示例：

```bash
curl --request POST \
  'https://open.musedam.cc/api/product/brands' \
  --header 'Authorization: Bearer your_api_key' \
  --header 'Content-Type: application/json' \
  --data-raw '{
  "name": "Example brand"
}'
```

### 刪除品牌

**接口路徑**：/brands/&#123;id&#125;

**接口描述**：僅可刪除沒有有效分類或商品的品牌，否則返回 409；絕不會級聯刪除商品。

所需角色：manage。

**請求參數**：

| 參數名 | 類型 | 必填 | 描述 |
| - | - | - | - |
| id | Integer | 是 | 路徑參數。正的有符號 32 位資源 ID。最小值：1；最大值：2,147,483,647 |
| If-Match | String | 否 | 請求頭參數。可選，帶引號的強 ETag、* 或以逗號分隔的候選標籤。弱標籤不會匹配。獲取行鎖後若因過期而不匹配，則返回 412 且不執行寫入；省略時採用最後寫入者獲勝。協調前請重新獲取當前數據。不支持 If-None-Match/304。 |

**響應參數**：

| 字段名 | 類型 | 描述 |
| - | - | - |
| success | Boolean | 請求成功時為 true。 |
| data | DeletedId | 返回的數據，字段見下表。 |
| code | String | 請求成功時為 null。 |
| message | String | 請求成功時為 null。 |
| requestId | String | 請求標識符，UUID 格式。 |

**DeletedId參數說明**：

| 字段名 | 類型 | 描述 |
| - | - | - |
| id | Integer | 資源 ID。最小值：1；最大值：2,147,483,647 |

成功響應：200。

**示例**：

### 創建草稿商品

**接口路徑**：/products

**請求方式**：POST

**接口描述**：僅創建草稿。創建時解析並固定一個模板版本；模板字段依據該不可變定義進行校驗。可關聯同一商品庫中現有的 FilePath ID；不支持上傳、遠程導入或回寫到提供方。冪等重放會保留原始標量結果/ETag，並且僅對在當前同一槽位中仍然有效的原始媒體按當前權限重新投影。

所需角色：editable 或 manage。

| 參數名 | 類型 | 必填 | 描述 |
| - | - | - | - |
| Idempotency-Key | String | 否 | 請求頭參數。可選，非空白且不含 ASCII 控制字符。作用域為團隊、key 和創建操作，有效期 24 小時。相同的規範化載荷會重放 201 及原始標量結果/ETag；載荷變更則返回 409。商品媒體會依據當前授權和有效的原始同槽位關聯重新投影。最短 1 個字符；最長 255 個字符 |
| - | ProductCreate | 是 | JSON 請求體：application/json |

**ProductCreate參數說明**：

## 權限與資料範圍

- 使用前先完成[取得授權](./product-library#authentication-and-scope)。每次請求依密鑰所屬團隊和協作者目前角色驗證，不繼承密鑰建立者的權限。
- 請求參數不能切換團隊、商品庫或操作者。商品庫 API 不提供密鑰及協作者管理接口。
- 移除協作者不會刪除既有分享和歷史記錄；停止分享需呼叫[撤銷分享](#operation-revokeProductShare)。密鑰失效及認證服務無法使用時的處理見[錯誤碼](./product-library-write-conventions#error-catalog)。

## 回應與分頁

JSON 接口使用以下結構。下載和匯出成功時直接回傳檔案。

| 回傳內容 | 讀取方式 |
| --- | --- |
| 操作成功 | `success: true`，從 `data` 讀取結果；`code`、`message` 為 `null`。 |
| 操作失敗 | `success: false`，`data: null`；依 HTTP 狀態碼和 `code` 處理，不依賴 `message` 的文案。 |
| 參數驗證失敗 | 從 `details[].field` 和 `details[].message` 找到需要修正的欄位。 |
| 請求追蹤 | 保留 `requestId` 或回應標頭 `X-Request-Id`，用於排查問題。 |

一般列表使用 `page` 和 `pageSize`，在回應頂層回傳 `pagination`：

| 參數 | 預設值 | 範圍 |
| --- | --- | --- |
| `page` | `1` | 從 `1` 開始的整數。 |
| `pageSize` | `20` | 正整數，超過 `100` 時以 `100` 處理。 |

```json
{
  "page": 1,
  "pageSize": 20,
  "totalCount": 42,
  "totalPages": 3
}
```

商品和素材可能在請求期間變為不可見，因此實際回傳筆數可能少於 `pageSize`，計數仍保留分頁時的結果。單一資源不可見時回傳 `404`。

需要持續同步商品時，請使用[游標同步](./product-library-synchronization)，不要依靠一般頁碼列表。篩選參數見具體接口；一般查詢會忽略未知參數，JSON 請求主體會拒絕未知欄位。

### 欄位格式

| 欄位 | 使用方式 |
| --- | --- |
| 數值型資源 ID | 正整數，最大 `2147483647`。 |
| 範本、分組、欄位、版本 ID | 字串，原樣保存，不假定為 UUID。 |
| 素材 ID | 使用素材查詢回傳的 `id`（FilePath ID），不能替換成 AssetObject ID 或商品關聯 ID。 |
| 分類 `iconAssetId` | 使用分類圖示的識別碼（CategoryIconAsset）。 |
| `size` | 十進位字串或 `null`，避免大型檔案位元組數失去精度。 |
| 日期 | RFC 3339 字串或 `null`；同步時間戳記保留完整六位小數。 |
| 商品 SKU | API 欄位名稱為 `spu`。 |

舊版或無法解析的商品媒體可能回傳 `id: null`。有效的媒體引用不會被截斷。預覽和下載連結的使用方式見[媒體連結](./product-library-product-writes#media-and-expiry)。

所有回應攜帶 `Cache-Control: private, no-store`。JSON 操作和錯誤使用 `application/json`。請求大小、批次數量等上限見[請求限制](./product-library-write-conventions#request-limits)。
