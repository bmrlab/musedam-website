## 使用本參考

在 Base URL（`https://open.musedam.cc/api/product`）後添加下方接口路徑即可調用。

[認證與權限](./product-library#authentication-and-scope) · [下載 OpenAPI JSON](/assets/developers/product-library/openapi.json) · [響應格式與限制](./product-library#wire-format-and-identifiers)

示例從服務端安全配置中讀取 PRODUCT_LIBRARY_API_KEY。運行前，請設置示例中使用的資源 ID、冪等鍵或 ETag。請求體中的資源 ID 和業務數據僅用於說明格式，須替換為當前商品庫中的有效值。

## 獲取品牌列表

**接口路徑**：/brands

**請求方式**：GET

**接口描述**：返回公開元數據，按 sortOrder 再按 id 排序。不包含原始 logo URL。

所需角色：view_only、usable、editable 或 manage。

**請求參數**：

| 參數名 | 類型 | 必填 | 描述 |
| - | - | - | - |
| page | Integer | 否 | 查詢參數。普通分頁頁碼。sync=true 時不允許使用。偏移量過大導致整數溢出時會被拒絕。最小值：1；默認值：1 |
| pageSize | Integer | 否 | 查詢參數。每頁條數；超過 100 的值會被限制為 100。非正數/非整數值會被拒絕。最小值：1；默認值：20 |

**響應參數**：

| 字段名 | 類型 | 描述 |
| - | - | - |
| success | Boolean | 請求成功時為 true。 |
| data | List&lt;Brand&gt; | 返回的數據，字段見下表。 |
| code | String | 請求成功時為 null。 |
| message | String | 請求成功時為 null。 |
| requestId | String | 請求標識符，UUID 格式。 |
| pagination | Page | 分頁信息，字段見下表。 |

**Brand參數說明**：

| 字段名 | 類型 | 描述 |
| - | - | - |
| id | Integer | 資源 ID。最小值：1；最大值：2,147,483,647 |
| name | String | 名稱。 |
| code | String | 編碼。 |
| description | String | 說明。可為 null |
| website | String | 網站地址。可為 null |
| sortOrder | Integer | 排序值。 |
| isEnabled | Boolean | 是否啓用。 |
| createdAt | String | RFC 3339 UTC 時間戳字符串。請保留全部小數位；同步中商品的 updatedAt 使用六位小數。格式：date-time |
| updatedAt | String | RFC 3339 UTC 時間戳字符串。請保留全部小數位；同步中商品的 updatedAt 使用六位小數。格式：date-time |

**Page參數說明**：

| 字段名 | 類型 | 描述 |
| - | - | - |
| page | Integer | 當前頁碼。最小值：1 |
| pageSize | Integer | 每頁數量。最小值：1；最大值：100 |
| totalCount | Integer | 總數量。最小值：0 |
| totalPages | Integer | 總頁數。最小值：0 |

成功響應：200。 完整定義：[BrandListResponse](#schema-BrandListResponse)

響應頭：[Cache-Control](#header-Cache-Control)、[X-Request-Id](#header-X-Request-Id)

[查看錯誤處理](./product-library#error-catalog)。

**示例**：

請求示例：

```bash
: "${PRODUCT_LIBRARY_API_KEY:?Set the API key from secure storage}"
curl --silent --show-error --fail-with-body --request GET \
  "https://open.musedam.cc/api/product/brands?page=1&pageSize=20" \
  --header "Authorization: Bearer $PRODUCT_LIBRARY_API_KEY"
```

## 創建品牌

**接口路徑**：/brands

**請求方式**：POST

**接口描述**：創建品牌；允許名稱重復，code 由服務端生成。logo 主機限制請參閱 BrandCreate。

所需角色：manage。

**請求參數**：

| 參數名 | 類型 | 必填 | 描述 |
| - | - | - | - |
| Idempotency-Key | String | 否 | 請求頭參數。可選，非空白且不含 ASCII 控制字符。作用域為團隊、key 和創建操作，有效期 24 小時。相同的規範化載荷會重放 201 及原始標量結果/ETag；載荷變更則返回 409。商品媒體會依據當前授權和有效的原始同槽位關聯重新投影。最短 1 個字符；最長 255 個字符 |
| - | BrandCreate | 是 | JSON 請求體：application/json |

**BrandCreate參數說明**：

不接受未定義字段。

| 字段名 | 類型 | 必填 | 描述 |
| - | - | - | - |
| name | String | 是 | 校驗前會去除首尾空白。最短 1 個字符；最長 128 個字符 |
| description | String | 否 | 最長 512 個字符；可為 null |
| logoUrl | String | 否 | null/空值表示清除。僅支持 HTTP(S)，不得包含憑據，且須為允許列表中的 MuseDAM CDN 或已配置的存儲主機；存儲前會移除 query 和 fragment。不支持上傳；讀取時不會返回。最長 512 個字符；可為 null |

**響應參數**：

| 字段名 | 類型 | 描述 |
| - | - | - |

| code | String | 請求成功時為 null。 |
| message | String | 請求成功時為 null。 |
| requestId | String | 請求標識符，UUID 格式。 |

**Brand參數說明**：

| 字段名 | 類型 | 描述 |
| - | - | - |
| id | Integer | 資源 ID。最小值：1；最大值：2,147,483,647 |
| name | String | 名稱。 |
| code | String | 編碼。 |
| description | String | 說明。可為 null |
| website | String | 網站地址。可為 null |
| sortOrder | Integer | 排序值。 |
| isEnabled | Boolean | 是否啓用。 |
| createdAt | String | RFC 3339 UTC 時間戳字符串。請保留全部小數位；同步中商品的 updatedAt 使用六位小數。格式：date-time |
| updatedAt | String | RFC 3339 UTC 時間戳字符串。請保留全部小數位；同步中商品的 updatedAt 使用六位小數。格式：date-time |

成功響應：201。 完整定義：[BrandResponse](#schema-BrandResponse)

響應頭：[Cache-Control](#header-Cache-Control)、[X-Request-Id](#header-X-Request-Id)、[ETag](#header-ETag)

[查看錯誤處理](./product-library#error-catalog)。

不接受未定義字段；至少提供字段數：1。

| - | - | - | - |
| id | Integer | 是 | 路徑參數。正的有符號 32 位資源 ID。最小值：1；最大值：2,147,483,647 |
| assetKey | String | 是 | 路徑參數。對商品下載候選列表返回的選擇 key 進行 URL 編碼；它不是 FilePath 或 AssetObject ID。最短 1 個字符；最長 256 個字符 |
| Idempotency-Key | String | 否 | 請求頭參數。可選非空白值，不含 ASCII 控制字符，最多 255 個字符。作用域為團隊、API key 和下載操作，保留 24 小時。相同輸入復用業務記錄，但會重新鑒權、讀取當前內容並再次傳輸，不緩存文件字節。POST 與單文件 GET 的操作作用域不同。輸入變化返回 409。省略、使用新 key 或過期後產生新記錄；去重並非永久有效。最短 1 個字符；最長 255 個字符 |

**響應參數**：

成功時返回附件，不使用 JSON 成功響應結構。示例將響應保存為本地文件；附件開始交付前的錯誤仍使用統一 JSON 錯誤結構。

| 參數名 | 類型 | 描述 |
| - | - | - |
| HTTP 狀態碼 | Integer | 200 |
| - | application/octet-stream | 響應體為文件字節。 |

響應頭：[Cache-Control](#header-Cache-Control)、[X-Request-Id](#header-X-Request-Id)、[Content-Disposition](#header-Content-Disposition)、[X-Download-Record-Id](#header-X-Download-Record-Id)、[X-Idempotency-Replayed](#header-X-Idempotency-Replayed)

[查看錯誤處理](./product-library#error-catalog)。

409：原文件不可用，或冪等鍵被用於不同的輸入。 [錯誤詳情](#response-Error409ProductDownloadAttachment)

413：請求體、所選文件數量或下載總大小超出限制。 [錯誤詳情](#response-Error413ProductDownloadAttachment)

**示例**：

請求示例：

PRODUCT_LIBRARY_ASSET_KEY_ENCODED 須為下載候選列表返回的 key 經 URL 編碼後的值，不能替換為 FilePath 或 AssetObject ID。

```bash
: "${PRODUCT_LIBRARY_API_KEY:?Set the API key from secure storage}"
: "${PRODUCT_LIBRARY_PRODUCT_ID:?Set the resource identifier before running this example}"
: "${PRODUCT_LIBRARY_ASSET_KEY_ENCODED:?Set the resource identifier before running this example}"
: "${PRODUCT_LIBRARY_IDEMPOTENCY_KEY:?Set the value for this request before running this example}"
curl --silent --show-error --fail-with-body --request GET \
  "https://open.musedam.cc/api/product/products/${PRODUCT_LIBRARY_PRODUCT_ID}/download-assets/${PRODUCT_LIBRARY_ASSET_KEY_ENCODED}" \
  --header "Authorization: Bearer $PRODUCT_LIBRARY_API_KEY" \
  --header "Idempotency-Key: $PRODUCT_LIBRARY_IDEMPOTENCY_KEY" \
  --output product-asset.bin
```
