## 读取接口文档

将[开发者文档索引](https://www.musedam.cc/zh-CN/developers/llms.txt)、[商品库概览 Markdown](https://www.musedam.cc/zh-CN/developers/markdown/product-library.md)和 [OpenAPI 契约](/assets/developers/product-library/openapi.json)提供给 AI 助手。页面工具栏支持复制可直接使用的提示词和当前文档 Markdown。这些内容公开可读，无需代码仓库权限。

&#62; 实现前先阅读商品库概览和接口参考。使用 https://open.musedam.cc/api/product 作为 Base URL，根据目标操作确定所需协作者角色，只使用文档中的端点和字段。同步商品时遵循游标协议，并核对可见性。将凭据保存在安全的本地或服务端配置中。

## 配置凭据与权限

使用现有 MuseDAM API Key，并由商品库管理员在「成员设置 → 添加成员」中将其添加为 API Key 协作者。初始角色为 `view_only`，请按目标操作分配角色。商品库不签发密钥，各项操作权限由角色统一决定。

将密钥保存在环境变量 `PRODUCT_LIBRARY_API_KEY` 中，不要粘贴到文档或提交到仓库。请求使用 `Authorization: Bearer <key>`，详见[认证与权限](./product-library#authentication-and-scope)。
