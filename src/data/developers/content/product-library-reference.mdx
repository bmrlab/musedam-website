## 查找接口

首次接入请先阅读[快速接入](./product-library)，完成授权并发起第一次请求。本页按资源列出接口的参数、请求与响应示例。

服务地址：`https://open.musedam.cc/api/product`。在服务地址后添加接口路径即可调用；示例中的 `your_api_key` 和资源 ID 需替换为实际值。

### 获取品牌列表

**接口路径**：/brands

**请求方式**：GET

**接口描述**：返回公开元数据，按 sortOrder 再按 id 排序。不包含原始 logo URL。

所需角色：view_only、usable、editable 或 manage。

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 |
| - | - | - | - |
| page | Integer | 否 | 查询参数。普通分页页码。sync=true 时不允许使用。偏移量过大导致整数溢出时会被拒绝。最小值：1；默认值：1 |
| pageSize | Integer | 否 | 查询参数。每页条数；超过 100 的值会被限制为 100。非正数/非整数值会被拒绝。最小值：1；默认值：20 |

**响应参数**：

| 字段名 | 类型 | 描述 |
| - | - | - |
| success | Boolean | 请求成功时为 true。 |
| data | List&lt;Brand&gt; | 返回的数据，字段见下表。 |
| code | String | 请求成功时为 null。 |
| message | String | 请求成功时为 null。 |
| requestId | String | 请求标识符，UUID 格式。 |
| pagination | Page | 分页信息，字段见下表。 |

**Brand参数说明**：

| 字段名 | 类型 | 描述 |
| - | - | - |
| id | Integer | 资源 ID。最小值：1；最大值：2,147,483,647 |
| name | String | 名称。 |
| code | String | 编码。 |
| description | String | 说明。可为 null |
| website | String | 网站地址。可为 null |
| sortOrder | Integer | 排序值。 |
| isEnabled | Boolean | 是否启用。 |
| createdAt | String | RFC 3339 UTC 时间戳字符串。请保留全部小数位；同步中商品的 updatedAt 使用六位小数。格式：date-time |
| updatedAt | String | RFC 3339 UTC 时间戳字符串。请保留全部小数位；同步中商品的 updatedAt 使用六位小数。格式：date-time |

**Page参数说明**：

| 字段名 | 类型 | 描述 |
| - | - | - |
| page | Integer | 当前页码。最小值：1 |
| pageSize | Integer | 每页数量。最小值：1；最大值：100 |
| totalCount | Integer | 总数量。最小值：0 |
| totalPages | Integer | 总页数。最小值：0 |

成功响应：200。

响应头：[Cache-Control](#header-Cache-Control)、[X-Request-Id](#header-X-Request-Id)

[查看错误处理](./product-library-write-conventions#error-catalog)。

**示例**：

请求示例：

```bash
curl --request GET \
  'https://open.musedam.cc/api/product/brands?page=1&pageSize=20' \
  --header 'Authorization: Bearer your_api_key'
```

### 创建品牌

**接口路径**：/brands

**请求方式**：POST

**接口描述**：创建品牌；允许名称重复，code 由服务端生成。logo 主机限制请参阅 BrandCreate。

所需角色：manage。

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 |
| - | - | - | - |
| Idempotency-Key | String | 否 | 请求头参数。可选，非空白且不含 ASCII 控制字符。作用域为团队、key 和创建操作，有效期 24 小时。相同的规范化载荷会重放 201 及原始标量结果/ETag；载荷变更则返回 409。商品媒体会依据当前授权和有效的原始同槽位关联重新投影。最短 1 个字符；最长 255 个字符 |
| - | BrandCreate | 是 | JSON 请求体：application/json |

**BrandCreate参数说明**：

不接受未定义字段。

| 字段名 | 类型 | 必填 | 描述 |
| - | - | - | - |

| description | String | 否 | 最长 512 个字符；可为 null |
| logoUrl | String | 否 | null/空值表示清除。仅支持 HTTP(S)，不得包含凭据，且须为允许列表中的 MuseDAM CDN 或已配置的存储主机；存储前会移除 query 和 fragment。不支持上传；读取时不会返回。最长 512 个字符；可为 null |

**响应参数**：

| code | String | 编码。 |

| createdAt | String | RFC 3339 UTC 时间戳字符串。请保留全部小数位；同步中商品的 updatedAt 使用六位小数。格式：date-time |
| updatedAt | String | RFC 3339 UTC 时间戳字符串。请保留全部小数位；同步中商品的 updatedAt 使用六位小数。格式：date-time |

响应头：[Cache-Control](#header-Cache-Control)、[X-Request-Id](#header-X-Request-Id)、[ETag](#header-ETag)

### 删除品牌

所需角色：manage。

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 |
| - | - | - | - |
| id | Integer | 是 | 路径参数。正的有符号 32 位资源 ID。最小值：1；最大值：2,147,483,647 |

**响应参数**：

| 字段名 | 类型 | 描述 |

| data | DeletedId | 返回的数据，字段见下表。 |
| code | String | 请求成功时为 null。 |
| message | String | 请求成功时为 null。 |
| requestId | String | 请求标识符，UUID 格式。 |

**DeletedId参数说明**：

| 字段名 | 类型 | 描述 |
| - | - | - |
| id | Integer | 资源 ID。最小值：1；最大值：2,147,483,647 |

### 创建草稿商品

**接口路径**：/products

**请求方式**：POST

**接口描述**：仅创建草稿。创建时解析并固定一个模板版本；模板字段依据该不可变定义进行校验。可关联同一商品库中现有的 FilePath ID；不支持上传、远程导入或回写到提供方。幂等重放会保留原始标量结果/ETag，并且仅对在当前同一槽位中仍然有效的原始媒体按当前权限重新投影。

所需角色：editable 或 manage。

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 |
| - | - | - | - |
| Idempotency-Key | String | 否 | 请求头参数。可选，非空白且不含 ASCII 控制字符。作用域为团队、key 和创建操作，有效期 24 小时。相同的规范化载荷会重放 201 及原始标量结果/ETag；载荷变更则返回 409。商品媒体会依据当前授权和有效的原始同槽位关联重新投影。最短 1 个字符；最长 255 个字符 |
| - | ProductCreate | 是 | JSON 请求体：application/json |

**ProductCreate参数说明**：

## 权限与数据范围

- 使用前先完成[获取授权](./product-library#authentication-and-scope)。每次请求按密钥所属团队和协作者当前角色校验，不继承密钥创建者的权限。
- 请求参数不能切换团队、商品库或操作者。商品库 API 不提供密钥及协作者管理接口。
- 移除协作者不会删除已有分享和历史记录；停止分享需调用[撤销分享](#operation-revokeProductShare)。密钥失效及认证服务不可用时的处理见[错误码](./product-library-write-conventions#error-catalog)。

## 响应与分页

JSON 接口使用以下结构。下载和导出成功时直接返回文件。

| 返回内容 | 读取方式 |
| --- | --- |
| 操作成功 | `success: true`，从 `data` 读取结果；`code`、`message` 为 `null`。 |
| 操作失败 | `success: false`，`data: null`；按 HTTP 状态码和 `code` 处理，不依赖 `message` 的文案。 |
| 参数校验失败 | 从 `details[].field` 和 `details[].message` 查找需要修正的字段。 |
| 请求追踪 | 保存 `requestId` 或响应头 `X-Request-Id`，用于排查问题。 |

普通列表使用 `page` 和 `pageSize`，在响应顶层返回 `pagination`：

| 参数 | 默认值 | 范围 |
| --- | --- | --- |
| `page` | `1` | 从 `1` 开始的整数。 |
| `pageSize` | `20` | 正整数，超过 `100` 时按 `100` 处理。 |

```json
{
  "page": 1,
  "pageSize": 20,
  "totalCount": 42,
  "totalPages": 3
}
```

商品和素材可能在请求期间变为不可见，因此实际返回条数可能少于 `pageSize`，计数仍保留分页时的结果。单项资源不可见时返回 `404`。

需要持续同步商品时，请使用[游标同步](./product-library-synchronization)，不要依靠普通页码列表。筛选参数见具体接口；普通查询会忽略未知参数，JSON 请求体会拒绝未知字段。

### 字段格式

| 字段 | 使用方式 |
| --- | --- |
| 数值型资源 ID | 正整数，最大 `2147483647`。 |
| 模板、分组、字段、版本 ID | 字符串，原样保存，不假定为 UUID。 |
| 素材 ID | 使用素材查询返回的 `id`（FilePath ID），不能替换成 AssetObject ID 或商品关联 ID。 |
| 分类 `iconAssetId` | 使用分类图标的标识符（CategoryIconAsset）。 |
| `size` | 十进制字符串或 `null`，避免大文件字节数丢失精度。 |
| 日期 | RFC 3339 字符串或 `null`；同步时间戳保留完整六位小数。 |
| 商品 SKU | API 字段名为 `spu`。 |

旧版或无法解析的商品媒体可能返回 `id: null`。有效的媒体引用不会被截断。预览和下载链接的使用方式见[媒体链接](./product-library-product-writes#media-and-expiry)。

所有响应携带 `Cache-Control: private, no-store`。JSON 操作和错误使用 `application/json`。请求大小、批量数量等上限见[请求限制](./product-library-write-conventions#request-limits)。
