## 使用本参考

本参考覆盖 17 条路径上的 31 个操作。以下接口路径均相对于生产环境 Base URL。所有语言的 JSON 字段名、枚举值和示例数据保持一致。

```text
https://open.musedam.cc/api/product
```

[下载 OpenAPI 3.0 规范（英文 JSON）](/assets/developers/product-library/openapi.json) · [商品库接口概览](./product-library) · [集成示例](./product-library-examples)

参数和请求体须符合链接中的完整数据结构。所有请求体（包括 GET）上限为 1,048,576 字节。示例仅用于说明格式，不包含可用凭据或真实资源 ID。

**身份认证**

每次请求均通过 Authorization: Bearer 传入现有 MuseDAM API key。请由服务端通过 HTTPS 发起请求。

具有显式团队范围协作者授权的现有 MuseDAM API key。请通过 HTTPS 发送 Authorization: Bearer &lt;key&gt;。所分配的本地角色决定操作能力，与创建者无关；每个获准请求都会在上游校验调用方 key。已移除或未添加的 key 无法访问。上游不可用时拒绝访问。

操作能力由 API Key 协作者当前的本地角色派生，不是可独立勾选的 API key scope。条件能力检查取决于请求的操作或返回的媒体。

现有 MuseDAM API key 需要显式的团队范围 API Key 协作者授权，并实时在上游校验调用方 key。操作能力仅由当前本地角色决定；不再提供可选的操作白名单。MuseDAM 管理凭据签发和生命周期；此 API 不提供密钥管理或协作者端点。JSON 操作使用标准响应结构；成功的下载和导出返回附件。所有请求体（包括 GET）上限为 1048576 字节。附件开始交付前的错误使用统一 Error 结构。v1 不提供 CORS/速率限制契约、429、批量写入、multipart 上传、webhook 或审批回调。锁冲突回滚返回 503 write_conflict 和 Retry-After: 1；已提交但响应不可用的变更返回 409 mutation_response_unavailable，并明确提供 mutationOutcome。

`createProduct` · **允许的协作者角色**: `editable`, `manage`

仅创建草稿。创建时解析并固定一个模板版本；模板字段依据该不可变定义进行校验。可关联同一商品库中现有的 FilePath ID；不支持上传、远程导入或回写到提供方。幂等重放会保留原始标量结果/ETag，并且仅对在当前同一槽位中仍然有效的原始媒体按当前权限重新投影。
