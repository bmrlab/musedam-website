## 使用本参考

在 Base URL（`https://open.musedam.cc/api/product`）后添加下方接口路径即可调用。

[认证与权限](./product-library#authentication-and-scope) · [下载 OpenAPI JSON](/assets/developers/product-library/openapi.json) · [响应格式与限制](./product-library#wire-format-and-identifiers)

示例从服务端安全配置中读取 PRODUCT_LIBRARY_API_KEY。运行前，请设置示例中使用的资源 ID、幂等键或 ETag。请求体中的资源 ID 和业务数据仅用于说明格式，须替换为当前商品库中的有效值。

## 获取品牌列表

**接口路径**：/brands

**请求方式**：GET

**接口描述**：返回公开元数据，按 sortOrder 再按 id 排序。不包含原始 logo URL。

所需角色：view_only、usable、editable 或 manage。

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 |
| - | - | - | - |
| page | Integer | 否 | 查询参数。普通分页页码。sync=true 时不允许使用。偏移量过大导致整数溢出时会被拒绝。最小值：1；默认值：1 |
| pageSize | Integer | 否 | 查询参数。每页条数；超过 100 的值会被限制为 100。非正数/非整数值会被拒绝。最小值：1；默认值：20 |

**响应参数**：

| 字段名 | 类型 | 描述 |
| - | - | - |
| success | Boolean | 请求成功时为 true。 |
| data | List&lt;Brand&gt; | 返回的数据，字段见下表。 |
| code | String | 请求成功时为 null。 |
| message | String | 请求成功时为 null。 |
| requestId | String | 请求标识符，UUID 格式。 |
| pagination | Page | 分页信息，字段见下表。 |

**Brand参数说明**：

| 字段名 | 类型 | 描述 |
| - | - | - |
| id | Integer | 资源 ID。最小值：1；最大值：2,147,483,647 |
| name | String | 名称。 |
| code | String | 编码。 |
| description | String | 说明。可为 null |
| website | String | 网站地址。可为 null |
| sortOrder | Integer | 排序值。 |
| isEnabled | Boolean | 是否启用。 |
| createdAt | String | RFC 3339 UTC 时间戳字符串。请保留全部小数位；同步中商品的 updatedAt 使用六位小数。格式：date-time |
| updatedAt | String | RFC 3339 UTC 时间戳字符串。请保留全部小数位；同步中商品的 updatedAt 使用六位小数。格式：date-time |

**Page参数说明**：

| 字段名 | 类型 | 描述 |
| - | - | - |
| page | Integer | 当前页码。最小值：1 |
| pageSize | Integer | 每页数量。最小值：1；最大值：100 |
| totalCount | Integer | 总数量。最小值：0 |
| totalPages | Integer | 总页数。最小值：0 |

成功响应：200。 完整定义：[BrandListResponse](#schema-BrandListResponse)

响应头：[Cache-Control](#header-Cache-Control)、[X-Request-Id](#header-X-Request-Id)

[查看错误处理](./product-library#error-catalog)。

**示例**：

请求示例：

```bash
: "${PRODUCT_LIBRARY_API_KEY:?Set the API key from secure storage}"
curl --silent --show-error --fail-with-body --request GET \
  "https://open.musedam.cc/api/product/brands?page=1&pageSize=20" \
  --header "Authorization: Bearer $PRODUCT_LIBRARY_API_KEY"
```

## 创建品牌

**接口路径**：/brands

**请求方式**：POST

**接口描述**：创建品牌；允许名称重复，code 由服务端生成。logo 主机限制请参阅 BrandCreate。

所需角色：manage。

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 |
| - | - | - | - |
| Idempotency-Key | String | 否 | 请求头参数。可选，非空白且不含 ASCII 控制字符。作用域为团队、key 和创建操作，有效期 24 小时。相同的规范化载荷会重放 201 及原始标量结果/ETag；载荷变更则返回 409。商品媒体会依据当前授权和有效的原始同槽位关联重新投影。最短 1 个字符；最长 255 个字符 |
| - | BrandCreate | 是 | JSON 请求体：application/json |

**BrandCreate参数说明**：

不接受未定义字段。

| 字段名 | 类型 | 必填 | 描述 |
| - | - | - | - |
| name | String | 是 | 校验前会去除首尾空白。最短 1 个字符；最长 128 个字符 |
| description | String | 否 | 最长 512 个字符；可为 null |
| logoUrl | String | 否 | null/空值表示清除。仅支持 HTTP(S)，不得包含凭据，且须为允许列表中的 MuseDAM CDN 或已配置的存储主机；存储前会移除 query 和 fragment。不支持上传；读取时不会返回。最长 512 个字符；可为 null |

**响应参数**：

| 字段名 | 类型 | 描述 |
| - | - | - |
| success | Boolean | 请求成功时为 true。 |
| data | Brand | 返回的数据，字段见下表。 |
| code | String | 请求成功时为 null。 |
| message | String | 请求成功时为 null。 |
| requestId | String | 请求标识符，UUID 格式。 |

**Brand参数说明**：

| 字段名 | 类型 | 描述 |
| - | - | - |
| id | Integer | 资源 ID。最小值：1；最大值：2,147,483,647 |
| name | String | 名称。 |
| code | String | 编码。 |
| description | String | 说明。可为 null |
| website | String | 网站地址。可为 null |
| sortOrder | Integer | 排序值。 |
| isEnabled | Boolean | 是否启用。 |
| createdAt | String | RFC 3339 UTC 时间戳字符串。请保留全部小数位；同步中商品的 updatedAt 使用六位小数。格式：date-time |
| updatedAt | String | RFC 3339 UTC 时间戳字符串。请保留全部小数位；同步中商品的 updatedAt 使用六位小数。格式：date-time |

成功响应：201。 完整定义：[BrandResponse](#schema-BrandResponse)

响应头：[Cache-Control](#header-Cache-Control)、[X-Request-Id](#header-X-Request-Id)、[ETag](#header-ETag)

[查看错误处理](./product-library#error-catalog)。

409：品牌 code 冲突、幂等键被复用，或变更已提交但响应不可用。 [错误详情](#response-Error409_code_in_use_idempotency_key_reused)

**示例**：

请求示例：

```bash

  "https://open.musedam.cc/api/product/brands" \

  --header "Idempotency-Key: $PRODUCT_LIBRARY_IDEMPOTENCY_KEY" \
  --header 'Content-Type: application/json' \
  --data-raw '{
  "name": "Example brand"
}'
```

## 创建草稿商品

**接口路径**：/products

**请求方式**：POST

**接口描述**：仅创建草稿。创建时解析并固定一个模板版本；模板字段依据该不可变定义进行校验。可关联同一商品库中现有的 FilePath ID；不支持上传、远程导入或回写到提供方。幂等重放会保留原始标量结果/ETag，并且仅对在当前同一槽位中仍然有效的原始媒体按当前权限重新投影。

所需角色：editable 或 manage。

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 |
| - | - | - | - |
| Idempotency-Key | String | 否 | 请求头参数。可选，非空白且不含 ASCII 控制字符。作用域为团队、key 和创建操作，有效期 24 小时。相同的规范化载荷会重放 201 及原始标量结果/ETag；载荷变更则返回 409。商品媒体会依据当前授权和有效的原始同槽位关联重新投影。最短 1 个字符；最长 255 个字符 |
| - | ProductCreate | 是 | JSON 请求体：application/json |

**ProductCreate参数说明**：

始终创建草稿。显式指定的 templateId 必须是同一商品库中的有效模板，且优先使用。当 templateId 省略/为 null 且提供了非 null 的 categoryId 时，解析顺序为：分类或其祖先分类的绑定，然后是该分类所属品牌的绑定，最后是商品库默认模板。当 categoryId 省略或为 null 时，即使提供了 brandId，也仅考虑商品库默认模板。若未解析出任何模板，则商品没有模板。分类必须与最终品牌匹配；owner 必须是同一团队成员，默认为 null，而非 key 创建者。cover/images/related/自定义媒体合计最多 100 个引用。图片槽位要求使用图片；自定义媒体必须满足固定版本的数量/大小/类型限制。

## 下载原文件或导出商品

**接口路径**：/product-downloads

**请求方式**：POST

**接口描述**：返回一个原文件、所选原文件的 ZIP，或 XLSX/CSV/JSON 业务表格导出。需要 usable 及以上角色的当前读取和下载权限；usable 只能访问已发布商品。已接受的操作在交付前记入记录。导出链接默认指向需认证的单文件 GET URL；每次接受的提取有自己的业务记录。可选 Idempotency-Key 在 24 小时内保留一条记录，每次重试仍重新鉴权并传输当前内容。商品读取、预览和旧存储 downloadUrl 的访问不会由此操作记入记录。

所需角色：usable、editable 或 manage。

**请求参数**：
