## 素材检索

**接口路径**：/search-assets

**请求方式**：POST

**接口描述**：检索企业空间内的素材

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 |
|-|-|-|-|
| - | EnterpriseSearchReqVO | 是 | 素材检索参数 |

**EnterpriseSearchReqVO 参数说明**：

| 字段名 | 类型 | 必填 | 描述 |
|-|-|-|-|
| parentId | Long | 否 | 指定搜索目录（不包括根目录），包含所有子孙 |
| needChildren | Boolean | 否 | 是否需要子级目录下的素材，默认 false |
| extensions | List&lt;String> | 否 | 文件类型扩展名 |
| color | String | 否 | 颜色 |
| areaThreshold | Integer | 否 | 颜色占比，默认 20 |
| colorThreshold | Integer | 否 | 颜色精准度，默认 20 |

| maxLength | Long | 否 | 最大时长（视频、音频），单位 ms |
| minSize | Long | 否 | 最小文件大小，单位 B |
| maxSize | Long | 否 | 最大文件大小，单位 B |

|-|-|-|

| parentIds | List&lt;Long> | 父文件夹ID列表 |
| userId | String | 用户ID |
| name | String | 文件原始名称 |
| downloadUrl | String | 下载路径 |
| source | Integer | 素材来源(1:网页，2:上传，3:复制) |
| link | String | 网页链接 |
| extension | String | 文件后缀 |
| duration | Long | 视频时长 |
| size | Long | 文件大小(KB) |
| width | Integer | 文件宽度 |
| height | Integer | 文件高度 |
| description | String | 描述 |
| score | Integer | 评分 |
| createTime | Date | 创建时间 |
| createUser | String | 创建人 |
| updateTime | Date | 更新时间 |
| updateUser | Long | 更新人 |
| tags | List&lt;TagDTO> | 标签列表 |
| thumbnailAccessUrl | String | 缩略图访问路径 |
| imageContentAnalysis | ImageContentAnalysis | 智能解析内容 |
| publicUrl | String | 原图公开链接（带 w/h/mode/q/f/bg 处理参数）；未传处理参数或无公开链接时为空字符串 |
| externalApp | String | 外部应用标识；IngenOps 画布为 `ingenops`，无关联时为 `null` |

**外部关联说明**：`externalApp` 与 `externalResourceRef` 是响应字段，不是搜索筛选参数。仅已关联外部资源的素材返回关联值；普通素材两者为 `null`。IngenOps 画布的 `externalApp` 为 `ingenops`，`externalResourceRef` 为对应的 `workspace_ref`。其他集成通过不同的 `externalApp` 区分。仍只返回当前用户有权访问的素材。

### 版权管理与授权有效期

`/search-assets` 与 `/assets-by-ids` 返回的素材使用相同的版权与有效期规则，由团队 `licenseManagement` 开关决定：

- **开启版权管理**：读取 `licenseAgreements[].scopes[]` 中的授权有效期及状态。每份协议可以包含多个授权范围，应分别查看地区、渠道与有效期；不要用素材顶层有效期替代协议有效期。
- **关闭版权管理**：读取素材顶层 `validStartTime`、`validEndTime`、`isPermanent`、`validityStatus` 和 `daysToExpire`。`licenseAgreements` 为 `null` 或不返回。

以下为素材返回对象的补充字段，**不是搜索筛选参数**。搜索请求原有 `startTime` / `endTime` 表示更新时间范围，与素材有效期不同。

| 字段名 | 类型 | 描述 |
|-|-|-|
| licenseAgreements | List&lt;MaterialLicenseAgreementDTO> | 开启版权管理时的授权协议列表 |
| validStartTime | Date | 关闭版权管理时的素材有效开始时间 |
| validEndTime | Date | 关闭版权管理时的素材有效结束时间 |
| isPermanent | Boolean | 关闭版权管理时，素材是否永久有效 |
| validityStatus | Integer | 素材有效期状态：1=待生效，2=有效，3=即将过期，4=已过期，5=永久有效 |
| daysToExpire | Integer | 距离结束的剩余天数，向上取整；永久有效为 99999，未知为 -1 |

**MaterialLicenseAgreementDTO（`licenseAgreements` 元素）：**

| 字段名 | 类型 | 描述 |
|-|-|-|
| agreementId | Long | 协议 ID |
| agreementName | String | 协议名称 |
| rightHolder | String | 权利主体 |
| scopes | List&lt;AgreementScopeDTO> | 授权范围列表 |

**AgreementScopeDTO（`licenseAgreements[].scopes` 元素）：**

| 字段名 | 类型 | 描述 |
|-|-|-|
| authorizedRegion | String | 授权地区 |
| authorizedChannel | String | 授权渠道 |
| effectiveDate | Date | 授权有效期开始时间 |
| expireDate | Date | 授权有效期结束时间 |
| isPermanent | Integer | 协议范围是否永久有效：0=否，1=是；与素材顶层 Boolean 类型不同 |
| licenseStatus | String | 授权状态 |
| licenseStatusText | String | 授权状态显示文案 |

> 日期字段按接口实际序列化格式读取；未配置或未知的有效期不要自行解释为永久有效。

**TagDTO参数说明**：

| 字段名 | 类型 | 描述 |
|-|-|-|
| id | Long | 标签ID |
| name | String | 标签名称 |

**ImageContentAnalysis参数说明**：

| 字段名 | 类型 | 描述 |
|-|-|-|
| aiTags | String | 智能标签信息 |
| aiTitle | String | 智能标签名称 |
| aiDescription | String | 智能描述 |
| aiDetailedDescription | JSONArray | 智能描述详情 |

## 分享列表搜索

**接口路径**：/search-share

**请求方式**：POST

**接口描述**：检索分享链接内的素材

**请求参数**：

| password | String | 否 | - | 分享链接的提取码，如果分享设置了提取码则必填 |

| endPoint | Integer | 否 | 40 | 分页参数，结束索引位置，每页默认40条数据 |

## 以图搜图

**接口路径**：`/search-by-image`

**请求方式**：POST

检索付费团队内的相似素材，按相似度排序。至少提供一个图片来源；同时传多个时优先级为 `imageBase64` > `searchMaterialId` > `imagePublicUrl`。

| 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| searchMaterialId | Long | 条件 | 已入库素材 ID |
| imagePublicUrl | String | 条件 | 可直接下载的图片 URL |
| imageBase64 | String | 条件 | 纯 base64 或带 data:image/xxx;base64, 前缀 |

其余筛选、分页和响应与 `/search-assets` 一致，返回 `result.assets`、`result.total`。`region` 为查询图上的框选区域，不是 MCP 连接的国内/海外区域。`endPoint` 大于 1000 返回空结果。三个来源都未传，或素材 ID 不大于 0 且另外两个为空时返回参数错误。仅付费团队可用。

以图搜图的响应与 `/search-assets` 相同，`result.assets[]` 同样包含 `externalApp` 和 `externalResourceRef`，含义及无关联时的空值规则见上方素材响应说明。

```json
{
  "imagePublicUrl": "https://example.com/query.jpg",
  "parentId": 100,
  "needChildren": true,
  "startPoint": 0,
  "endPoint": 20
}
```
